# 08 — Каталог товаров для сотрудников

> Статус: ✅ утверждён — владелец делегировал решения по логике, дизайну и архитектуре (2026-07-10)

**Отдельное приложение с отдельной базой данных.** С Auron Finance не смешивается:
ни общего кода, ни общей базы, ни общего входа. Живёт и обновляется независимо.

## Какую проблему решаем

У части товаров нет штрихкода (бургеры, хот-доги, выпечка, весовой товар).
Кассир знает коды наизусть, но если за кассу сел сотрудник зала — путаница:
какой код у какого хот-дога. **Решение:** сотрудник открывает ссылку, находит товар
по фото или названию — видит все коды и правильно пробивает на кассе.

## Как это работает

### Сотрудник (по ссылке, без регистрации)
- Поиск как в Яндексе: понимает опечатки, часть слова, поиск по коду. Результат — картинками
- Группы товаров для поиска глазами. Товары без штрихкода помечены: «пробивать по коду»
- Карточка товара: все фото (листаются), название как в кассе, крупно код кассы,
  артикул, штрихкод, отдел, примечание. Любой код копируется одним тапом
- Работает и при плохом интернете: последняя версия каталога хранится на телефоне

### Владелец (один админ-аккаунт: email + пароль)
- Вход → появляются кнопки добавления и редактирования
- Добавить товар с телефона: сфотографировал (несколько фото), вписал название и коды,
  выбрал группу → сохранил. Сразу видно всем
- **Изменять можно всё сохранённое:** название, коды, группу, примечание; фото —
  добавить/удалить/заменить; товар — удалить целиком. С телефона и компьютера одинаково
- Группы товаров владелец создаёт/переименовывает/удаляет сам прямо в приложении
- Без входа в админ-аккаунт — только просмотр

### Чего каталог НЕ показывает
❌ Цены, остатки, поставщиков, деньги — по ссылке может зайти кто угодно.

## Принятые решения (делегированы владельцем)

| Вопрос | Решение |
|--------|---------|
| Название | «Way Market · Каталог» |
| Группы на старте | Хлебобулочные · Выпечка и фастфуд · Сладости · Напитки · Молочные · Бакалея · Химия · Прочее — владелец меняет список сам в приложении |
| Отдел кассы | Необязательное поле на карточке — показывается только если заполнено |
| Поиск рус ↔ англ | Транслитерация в обе стороны: «сникерс» найдёт Snickers, snickers найдёт «Сникерс» |
| Весовые товары | Отметка «⚖ Весовой» на товаре + отдельный фильтр «⚖ Весовые» рядом с группами; коды весовых ищутся как обычные |
| Поставщики | У товара указывается поставщик. Поиск находит по имени поставщика; чип «🚚 Поставщики» открывает список → тап показывает все товары поставщика; та же кнопка есть в карточке товара. Список поставщиков ведёт админ |
| Сканер для всех | Кнопка камеры рядом с поиском: сотрудник сканирует штрихкод → открывается карточка товара. Работает на Android (встроенный распознаватель) и iPhone (запасная библиотека html5-qrcode). У админа сканер также заполняет штрихкод в форме |
| Простота | Крупный текст, большие кнопки, минимум действий — удобно и старшему поколению, и молодым |
| База данных | Бесплатное облако Supabase (отдельный проект, не сервер Auron): в каталоге нет цен и личных данных, лимитов бесплатного тарифа хватает на тысячи товаров с фото |
| Фото | Сжимаются автоматически при загрузке (быстро открывается даже на слабом интернете) |
| Поиск | Мгновенный, прямо на телефоне: опечатки, часть слова, цифры кода |
| Дизайн | Мобильный в первую очередь; светлая и тёмная тема автоматически; стиль перекликается с Auron (зелёный акцент), но код независимый |

## Техника

| Что | Где | Цена |
|-----|-----|------|
| Код приложения | Папка `catalog/` в репозитории; публикуется на GitHub Pages по адресу `…/Auron/catalog/` (при желании владельца переносится в отдельный репозиторий со своей ссылкой — 5 минут) | ₽0 |
| База и фото | Отдельный бесплатный проект Supabase Cloud (таблицы товаров/групп + хранилище фото) | ₽0 |
| Админ-доступ | Встроенный вход Supabase (email + пароль), один пользователь; запись в базу разрешена только вошедшему, чтение — всем | ₽0 |

**Файлы:** `catalog/index.html` + `catalog/styles.css` + `catalog/js/app.js` + `catalog/js/config.js` (адрес и ключ базы) + `catalog/setup/schema.sql` (создание таблиц одним запуском) + `catalog/setup/НАСТРОЙКА.md` (пошаговая инструкция для владельца, 10 минут).

## Что осталось сделать владельцу
1. Зарегистрировать бесплатный проект на supabase.com по инструкции `catalog/setup/НАСТРОЙКА.md`
2. Прислать адрес проекта и ключ — вставим в `config.js`, каталог заработает
