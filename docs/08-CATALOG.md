# 08 — Каталог товаров для сотрудников

> Статус: 🔄 черновик — ждёт утверждения владельцем

## Какую проблему решаем

У части товаров нет штрихкода (бургеры, хот-доги, выпечка, весовой товар).
Кассир знает коды наизусть, но если за кассу сел сотрудник зала — начинается путаница:
какой код у какого хот-дога, как товар записан в кассе. Ошибки при пробитии, вопросы, задержки.

**Решение:** каталог-справочник. Сотрудник открывает ссылку на телефоне, находит товар
по фото или названию — и видит все коды, чтобы правильно пробить на кассе.

## Как это устроено

**Отдельная страница** (не внутри Auron Finance): открывается по ссылке,
без регистрации и паролей. Открыл → ищи.

### Что видит сотрудник
- **Поиск сверху** — как в Google/Яндексе: понимает опечатки, часть слова, поиск по коду.
  Начал печатать «хотд» → сразу показываются все хот-доги картинками
- **Группы товаров** — Химия, Сладости, Хлебобулочные, Напитки и т.д.
  Если не знаешь название — ищи глазами по группе
- **Карточка товара** — тап по товару открывает:
  - все фотографии (можно листать)
  - название как в кассе
  - код кассы, артикул, штрихкод
  - группа и примечание («пробивать по коду, штрихкода нет»)

### Что видит владелец (админ)
- Один аккаунт с логином и паролем — только у владельца
- Вход → появляются кнопки: добавить товар, изменить, удалить
- Добавить товар прямо с телефона: сфотографировал (несколько фото),
  вписал название и коды, выбрал группу → сохранил. Сразу видно всем

### Чего каталог НЕ показывает
- ❌ Цены (ни закупочные, ни продажные) — по ссылке может зайти кто угодно
- ❌ Остатки, деньги, поставщиков — это всё в Auron Finance для своих ролей

## Техника (коротко)

| Что | Где | Цена |
|-----|-----|------|
| Страница каталога | `app/catalog.html` → GitHub Pages (та же ссылка, что и приложение, + `/catalog`) | ₽0 |
| Список товаров | Наша база на сервере Timeweb (тот же сервер, что у Auron) | ₽0 (сервер уже оплачен) |
| Фотографии | Хранилище файлов на том же сервере | ₽0 |
| Умный поиск | Весь каталог загружается на телефон один раз → поиск мгновенный, работает с опечатками | ₽0 |
| Аккаунт админа | Тот же механизм входа, что у Auron (email + пароль) | ₽0 |

Фото при загрузке автоматически сжимаются — чтобы каталог открывался быстро даже на слабом интернете.

## Связь с Auron Finance

Каталог живёт в том же репозитории и на том же сервере, но работает независимо
от большого приложения (которое сейчас переписывается). Когда основное приложение
будет готово, раздел «Товары» для роли «Сотрудник зала» сможет использовать эту же
базу товаров — ничего заполнять заново не придётся.
