# 08 — Каталог товаров для сотрудников

> Статус: 🔄 черновик — ждёт утверждения владельцем

**Решение владельца:** каталог — полностью отдельное приложение со своей отдельной базой данных.
С Auron Finance не смешивается: ни общего кода, ни общей базы. Живёт и обновляется независимо.

## Какую проблему решаем

У части товаров нет штрихкода (бургеры, хот-доги, выпечка, весовой товар).
Кассир знает коды наизусть, но если за кассу сел сотрудник зала — начинается путаница:
какой код у какого хот-дога, как товар записан в кассе. Ошибки при пробитии, вопросы, задержки.

**Решение:** каталог-справочник. Сотрудник открывает ссылку на телефоне, находит товар
по фото или названию — и видит все коды, чтобы правильно пробить на кассе.

## Как это устроено

**Отдельная страница** (не внутри Auron Finance): открывается по ссылке,
без регистрации и паролей. Открыл → ищи.

### Что видит сотрудник
- **Поиск сверху** — как в Google/Яндексе: понимает опечатки, часть слова, поиск по коду.
  Начал печатать «хотд» → сразу показываются все хот-доги картинками
- **Группы товаров** — Химия, Сладости, Хлебобулочные, Напитки и т.д.
  Если не знаешь название — ищи глазами по группе
- **Карточка товара** — тап по товару открывает:
  - все фотографии (можно листать)
  - название как в кассе
  - код кассы, артикул, штрихкод
  - группа и примечание («пробивать по коду, штрихкода нет»)

### Что видит владелец (админ)
- Один аккаунт с логином и паролем — только у владельца
- Вход → появляются кнопки: добавить товар, изменить, удалить
- Добавить товар прямо с телефона: сфотографировал (несколько фото),
  вписал название и коды, выбрал группу → сохранил. Сразу видно всем
- **Редактирование сохранённого:** у любого товара можно изменить всё —
  название, коды, группу, примечание; фото — добавить новые, удалить старые,
  заменить; товар целиком — удалить. Изменения сразу видны всем сотрудникам
- Работает одинаково с телефона и с компьютера — разницы нет
- Без входа в админ-аккаунт изменить или удалить ничего нельзя — только смотреть

### Чего каталог НЕ показывает
- ❌ Цены (ни закупочные, ни продажные) — по ссылке может зайти кто угодно
- ❌ Остатки, деньги, поставщиков — это всё в Auron Finance для своих ролей

## Техника (коротко)

| Что | Где | Цена |
|-----|-----|------|
| Страница каталога | Отдельный проект на GitHub Pages — своя ссылка, не связана с Auron | ₽0 |
| Список товаров и фото | **Своя отдельная база данных** — не база Auron | ₽0 |
| Умный поиск | Весь каталог загружается на телефон один раз → поиск мгновенный, работает с опечатками | ₽0 |
| Аккаунт админа | Один аккаунт (email + пароль), свой у каталога — не связан с входом в Auron | ₽0 |

Фото при загрузке автоматически сжимаются — чтобы каталог открывался быстро даже на слабом интернете.

## Отдельность от Auron Finance

- Свой репозиторий (проект) на GitHub, своя ссылка
- Своя база данных: что бы ни происходило с Auron (переписывание, обновления), каталог не пострадает
- Свой вход для админа
- Общего — ничего. Единственная связь: этот документ лежит в памяти проекта, чтобы решение не потерялось

## Вопросы к владельцу (решить до кода)

1. **Где держать базу каталога** (в каталоге нет цен и личных данных — только фото и коды товаров):
   - **Вариант А (рекомендую):** бесплатное облако Supabase — ноль настройки, ноль нагрузки на наш сервер, бесплатно навсегда (лимитов хватит на тысячи товаров с фото)
   - **Вариант Б:** вторая отдельная база на нашем сервере Timeweb — данные у нас, но настройка сложнее и сервер будет нести двойную нагрузку
2. Список групп товаров — какие нужны на старте? (Химия, Сладости, Хлебобулочные, … — дополни)
3. Название на странице — «Way Market. Каталог» подойдёт?
4. Нужен ли на карточке номер отдела/секции кассы (если на кассе товары разбиты по отделам)?
