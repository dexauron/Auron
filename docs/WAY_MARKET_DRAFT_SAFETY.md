# Way Market 0.8.3 — сохранность несохранённого ввода

Основа: работа Claude 0.8.2 (`125542950d95d68ecd2f2f99af2cadadc2d22d77`, PR #43). Исправление подготовлено отдельно в `codex/cash-draft-safety`, без переписывания ветки Claude и рабочей ветки. Улучшения интерфейса, формулы и SQLite сохранены.

## Проблемы и новое поведение

1. Единственный ключ localStorage перезаписывался разными вкладками. Сохранение одного листа удаляло несохранённый ввод другого. Теперь ключ содержит редактор и отдельный ID черновика. Даже две правки одного сохранённого листа имеют отдельные копии. Успешное сохранение удаляет только текущую собственную копию.
2. Предложение восстановить старый снимок оставалось активным после нового ввода. Оно заменяло текущие поля без подтверждения. Теперь восстановление требует подтверждения, текущие поля сначала сохраняются отдельно; при сбое их сохранения предупреждение явно говорит о риске замены. Выбранный снимок перечитывается до и после ожидания ответа сервера. Отмена и ошибка не заменяют текущие поля.
3. Исключения localStorage проглатывались. Теперь сбой виден в закреплённой панели, сохранение на сервере доступно. Повреждённая копия не удаляется автоматически. Ошибка удаления после успешного серверного сохранения отличается от ошибки самого сохранения.

## Модель

`public/drafts.mjs` отвечает за чтение/запись, версии снимков и работу с ключами. Новый префикс — `way-market:excel-draft:v2:`. В копии остаются исходные значения, снимок настроек, реквизиты, ID/версия сохранённого листа и время; добавлены `format`, `owner`, `draftId`, `revision`.

Для текущей вкладки ID хранится в sessionStorage. Web Locks удерживает редактор до выхода со страницы: дублированная вкладка с унаследованным sessionStorage получает новый ID. Если Web Locks или sessionStorage недоступны, используются новые случайные ID, старые копии продолжают предлагаться. Удаление чужой копии без возможности проверить её активность ограничено; восстановление остаётся доступным. Новый формат не является шифрованием или авторизацией.

Копии разных листов и разных правок одного листа не объединяются. При восстановлении собственной копии продолжается работа с ней; чужая/старая копия копируется в новый слот и сохраняется до отдельного удаления. Удаление активной чужой копии блокируется её Web Lock. Удаление по старой кнопке проверяет, не изменился ли снимок.

Старый глобальный ключ `way-market:excel-draft` доступен для явного восстановления. Обновление не переписывает и не удаляет его автоматически. После сохранения восстановленного листа старая копия может остаться в списке; удалить её можно отдельной кнопкой. Черновики не очищаются по возрасту без решения пользователя.

При открытии другого листа после явного подтверждения отказа от текущей правки удаляется только её собственный черновик. На сервере новая версия по-прежнему требует причины и проверки текущей версии. Если версия сервера изменилась, восстановление правки останавливается, её копия и текущие поля остаются. Автоматического переноса старой правки поверх новой версии нет.

## Проверки

- 114 автоматических тестов. Из них 9 новых проверяют раздельность редакторов и слотов, устаревшие кнопки, совместимость старого формата, ошибки хранилища, повреждённые копии, дублированный sessionStorage и защиту активного редактора.
- `way-market/audit/cash-drafts-browser-check.mjs`: 6 изолированных сценариев на временной базе в памяти. Проверены две вкладки и перезагрузка; дублированная вкладка; запрет удаления активной копии; отмена/подтверждение восстановления с сохранением обоих вводов; две правки одного листа и новая версия сервера; предупреждение об отказе записи на экране 320 px и успешное сохранение на сервере; восстановление/явное удаление старого формата.
- Прежний `cash-sheet-browser-check.mjs` обновлён под окно выбора черновиков. Его сценарии прошли: расчёты, Enter, ввод сумм, исправления, история, печать, настройки, скрытые суммы, старые записи и размеры 1440×1000, 820×1180, 390×844, 320×740. Ошибок JS нет.
- Проверки выполнялись в Chromium на Linux, Node 24.19. Физические Windows/Edge, Safari/iPhone/Android и принтер отдельно не проверены.

Запуск изолированной проверки восстановления при установленном Playwright:

`PLAYWRIGHT_FROM=/path/to/package.json CHROMIUM=/path/to/chromium node way-market/audit/cash-drafts-browser-check.mjs`

Эта проверка сама создаёт сервер на случайном localhost-порту и базу в памяти. Она не читает и не меняет рабочую базу. Переменная `WAY_BROWSER_SINGLE_PROCESS=1` предназначена только для ограниченной среды проверки Chromium.

## Передача и обновление

Версия 0.8.3 включает работу Claude 0.8.2 и исправления черновиков. База и формулы не мигрируют. Перед обновлением выгрузить и проверить архив, остановить прежний процесс, распаковать программу в отдельную папку и запустить `start-server-test.cmd`. Папку `C:\ProgramData\WayMarket-Test` не удалять. Старые папки программы сохранить для отката.

Новые черновики 0.8.3 предыдущая версия не читает; при откате сначала сохранить нужные листы на сервере. Копии браузера не входят в архив SQLite и остаются в том профиле/браузере и на том origin, где вводились. Удаление профиля, очистка данных сайта и поломка диска могут удалить их. До авторизации и проверенного сетевого доступа использовать только вымышленные данные.
