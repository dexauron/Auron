# 09 — Auron-советник: приложение как ИИ (видение)

Статус: 🔄 черновик на утверждение владельцем

## Одна фраза
Превратить Auron из «таблицы с цифрами» в **финансового директора в кармане**:
он сам находит деньги, предупреждает заранее и отвечает по-человечески — и
работает даже без интернета.

## Почему это честный ИИ, а не хайп
Три из четырёх частей работают на **наших же данных и простой математике,
прямо в приложении** — без внешнего «мозга», без интернета, бесплатно.
Это и делает их надёжными. Настоящую нейросеть (свободные вопросы) можно
подключить позже как надстройку — она приятная, но не основа.

## Четыре опоры (владелец выбрал все)

### 1. 💰 Охотник за экономией — делаем ПЕРВЫМ
Приложение само сравнивает всех поставщиков (у нас 620) по каждому товару и
показывает конкретную экономию: «эти 34 товара выгоднее брать у другого —
≈ 47 000 ₽/мес». Плюс: рост цен, дорогие позиции, «замороженные» деньги.
**Почему первым:** максимальная польза, всё считается на данных, что уже есть,
окупает приложение сразу.

### 2. 🔔 Проактивный советник
Каждое утро одна фраза о главном + предупреждения заранее: кассовый разрыв
через N дней, товар кончится в среду, поставщик поднял цены, касса не сошлась.
Развитие «Пульса магазина» и «Мозга», которые уже есть.

### 3. 💬 Помощник (вопрос-ответ)
Пишешь или говоришь по-человечески — получаешь короткий ответ по данным
магазина: «сколько заработал вчера», «что не продаётся», «где дешевле молоко».
Сначала — понимание частых вопросов правилами (работает офлайн). Позже —
подключение настоящей нейросети для любых формулировок (нужен интернет).

### 4. 🛡️ Надёжность — параллельный фундамент
Чтобы всё это не падало:
- **Офлайн-режим:** нет интернета — приложение работает, потом само
  досинхронизируется.
- **Разбить один файл на модули:** одна ошибка не роняет всё приложение.
- **Автопроверки перед обновлением:** уже есть 60+ тестов, расширяем.

## Порядок работы (предложение)
1. Охотник за экономией (быстрая и ощутимая польза).
2. Проактивный советник (прогнозы: кассовый разрыв, «кончится товар»).
3. Помощник вопрос-ответ (правила → голос → позже нейросеть).
4. Надёжность — понемногу на каждом шаге (офлайн, модули, тесты).

## Опора №5 — «Живой разум» (думать как человек)
Владелец хочет, чтобы приложение думало как опытный человек: учитывало
район и адрес магазина, потребности населения, маркетинг, экономику и
новости, искало актуальные данные в интернете, само обучалось.
**Честно, что из этого реально — три уровня:**

**Уровень 1 — свои данные (уже есть, бесплатно, офлайн).** Приложение
«умнеет» само: копит историю продаж/цен, помнит решения владельца, видит
тренды и сезонность. Это и есть настоящее «обучение на практике».

**Уровень 2 — настоящий ИИ-мозг (нужен ключ, интернет, небольшая плата).**
Подключаем реальную нейросеть. Ей отдаём сводку по магазину + адрес/район +
сезон — она отвечает по-человечески и советует как консультант. Включается,
когда владелец добавит ключ ИИ в настройках. Пока ключа нет — работает
локальный помощник (по правилам).

**Уровень 3 — мир вокруг (по возможности, честно о границах).**
- Реально: курс/ключевая ставка/инфляция и крупные новости — через открытые
  источники; сезон и календарь праздников (влияют на спрос); район магазина
  описывает владелец, ИИ это учитывает.
- Ограничения (честно): читать «все чаты и обсуждения» в интернете нельзя —
  это закрытые/чужие данные. Точная демография района — платные сервисы.
  «Саморазвитие» — это накопление данных и память предпочтений, а не
  волшебный самостоятельно переписывающий себя ИИ.

Порядок для №5: сначала ИИ-мозг на своих данных (уровень 2) → потом
добавляем экономический и сезонный контекст (уровень 3) по мере надобности.

## Принципы
- Всё — простым языком, конкретные деньги и действия, без графиков-ребусов.
- Сначала считаем локально (надёжно, бесплатно, офлайн); внешний ИИ — опция.
- Честность важнее хайпа: не обещаем того, чего технически нельзя.
- Каждый шаг = отдельный маленький документ + код только после «да» владельца.
