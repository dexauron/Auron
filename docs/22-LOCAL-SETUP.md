# Как открыть приложение у себя на компьютере

Для Windows. Программировать не нужно — вводите команды по образцу.

---

## Что поставить: две программы

### 1. Node.js — обязательно

Он запускает сборку и проверки.

1. Откройте **nodejs.org**
2. Большая зелёная кнопка **LTS** (не «Current») — скачать
3. Запустить, жать **Next → Next → Install**
4. Перезагрузить компьютер (иначе команды не найдутся)

### 2. Git — чтобы забирать изменения

1. Откройте **git-scm.com/download/win**
2. Скачается сам, запустите
3. Жмите **Next** до конца, ничего не меняя

**Больше ничего не нужно.** Ни Android Studio, ни редакторов — они
понадобятся, только если будете сами править код.

### 3. VS Code — не обязателен, но удобнее

Бесплатный редактор от Microsoft. Даёт три вещи, ради которых стоит:

- **терминал внутри окна** — не нужно отдельно открывать `cmd`;
- **кнопки вместо команд для git** — забрать, сохранить, отправить;
- **страница сама обновляется** при изменении файла.

Скачать: **code.visualstudio.com**, синяя кнопка **Download for Windows**.
Установка: Next до конца. Одну галочку стоит включить —
**«Add to PATH»** (обычно включена).

## Работа через VS Code

### Открыть проект

**File → Open Folder** → выбрать папку `Auron` на Рабочем столе.
Слева появится дерево файлов.

Если проект ещё не скачан, можно прямо отсюда:
**View → Command Palette** (или `Ctrl+Shift+P`) → напечатать
`Git: Clone` → вставить `https://github.com/dexauron/Auron.git`.

### Открыть терминал внутри

**Ctrl + `** (клавиша под Esc) или **Terminal → New Terminal**.

Внизу откроется командная строка, уже в папке проекта — никуда
переходить не надо. Все команды из этого документа вводятся туда же.

### Собрать и посмотреть приложение

В терминале:

```
node android/build-www.js
```

> В VS Code работают косые черты в любую сторону — можно писать
> `android/build-www.js`, как в примерах для Mac.

Затем в дереве слева найдите `android` → `www` → `index.html`,
**правой кнопкой** → **Open with Live Server**.

Откроется браузер, и — главное — **страница будет сама обновляться**
каждый раз, когда вы пересоберёте приложение. Не надо жать F5.

Для этого нужно расширение — см. ниже.

### Три расширения, которые стоит поставить

Слева на панели значок с квадратиками (**Extensions**, `Ctrl+Shift+X`).
Ищите по названию, жмите **Install**:

| Расширение | Зачем |
|---|---|
| **Live Server** (Ritwick Dey) | страница сама обновляется при пересборке |
| **Russian Language Pack** | интерфейс редактора по-русски |
| **GitLens** | видно, кто и когда менял каждую строку |

Больше ничего не нужно. Списки «топ-30 расширений» из интернета
только замедлят редактор.

### Git кнопками, без команд

Слева значок с ветками (**Source Control**, `Ctrl+Shift+G`):

| Что нужно | Что нажать |
|---|---|
| Забрать свежие изменения | «…» вверху → **Pull** |
| Посмотреть, что я наменял | список файлов, щёлкнуть по файлу — покажет строки |
| Сохранить работу | вписать, что сделали, → галочка **Commit** |
| Отправить на GitHub | «…» → **Push** |

**Перед Commit обязательно прогоните проверки** в терминале — кнопка
их не запускает.

### Прогнать проверки

В терминале VS Code:

```
for /r webapp\tests %f in (*.test.js) do @node "%f"
```

Или по одному файлу, если ищете конкретную поломку:

```
node webapp/tests/calc.test.js
```

### Чем это лучше командной строки

Ничего принципиально нового VS Code не делает — те же команды. Но:
файлы видно списком, правки видно цветом, git не надо помнить, а
страница обновляется сама. Для человека без опыта это заметно проще.

## Как забрать проект к себе

Откройте командную строку (клавиша Windows → `cmd` → Enter) и введите
по очереди:

```
cd %USERPROFILE%\Desktop
git clone https://github.com/dexauron/Auron.git
cd Auron
```

На Рабочем столе появится папка **Auron** со всем проектом.

**Забрать свежие изменения** потом — одна команда из папки проекта:

```
git pull
```

## Как открыть приложение — два способа

### Способ А. Настоящее приложение (рекомендую)

Работает по-настоящему: можно завести счёт, записать смену, посмотреть
аналитику. Данные сохраняются в браузере, интернет не нужен.

```
node android\build-www.js
```

Появится файл **`android\www\index.html`** — откройте его двойным
щелчком. Это ровно то же, что внутри телефонного приложения.

> Данные хранятся отдельно от телефона: браузер на компьютере и
> телефон — два разных хранилища, они не связаны.

### Способ Б. Только внешний вид

Если нужно посмотреть вёрстку рабочей версии (той, что на Google), с
поддельными данными:

```
node .claude\skills\look\scripts\gas.js webapp\Index.html preview.html webapp\tests\fixtures\ui-stub.json
```

Появится **`preview.html`** — откройте в браузере. Данные ненастоящие,
кнопки сохранения не работают: сервера-то нет.

**Зачем этот способ, если есть первый:** он показывает именно рабочую
версию, включая экраны входа и знакомства, которых в телефонной нет.

## Как проверить, что ничего не сломано

Перед тем как что-то менять — и обязательно после:

```
bash .claude\skills\preflight\scripts\preflight.sh
```

Если `bash` не найдётся (в Windows его может не быть) — запускайте
части по отдельности:

```
node webapp\tests\calc.test.js
node webapp\tests\android-build.test.js
```

Все проверки разом:

```
for %f in (webapp\tests\*.test.js) do node "%f"
```

Зелёные галочки — всё хорошо. Красный крестик — что-то сломано,
**в таком виде выкладывать нельзя**.

## Как посмотреть, как выглядит на телефоне

Не нужен телефон — есть снимок экрана:

```
node .claude\skills\look\scripts\shot.js android\www\index.html
```

Появятся две картинки: `index-phone.png` (390×844, как телефон) и
`index-desktop.png` (1440×900, как компьютер).

Первый раз может ругнуться, что нет браузера для снимков — тогда:

```
npm install playwright-core
npx playwright install chromium
```

## Что где лежит

| Хотите поменять | Файл |
|---|---|
| Внешний вид, экраны, кнопки | `webapp\Index.html` |
| Расчёты, логику, правила | `webapp\Code.gs` |
| Значок приложения | `android\make-icons.py` |
| Тексты для программиста | `README.md`, `docs\` |

**Важно:** после правки `Index.html` или `Code.gs` нужно пересобрать
приложение (`node android\build-www.js`) — иначе увидите старое.

## Порядок работы, если решите править сами

1. `git pull` — забрать свежее
2. поправить файл
3. `node android\build-www.js` — пересобрать
4. открыть `android\www\index.html`, посмотреть глазами
5. прогнать проверки
6. `git add -A`, `git commit -m "что сделал"`, `git push`

Шаг 5 пропускать нельзя. Проверки ловят то, что глазами не видно, —
например, что цифры перестали сходиться.

---

## Если что-то не работает

| Что видите | Что делать |
|---|---|
| `node не является внутренней командой` | Node.js не установлен или не перезагрузили компьютер |
| `git не является внутренней командой` | то же самое с Git |
| Страница открылась пустой | пересоберите: `node android\build-www.js` |
| Красный крестик в проверках | пришлите текст ошибки — разберём |
