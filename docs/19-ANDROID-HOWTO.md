# Как сделать из Auron приложение для Android

Для владельца — не программиста. Два пути: без Android Studio и с ней.

---

## Сначала: что мы делаем

Наше приложение — это веб-страница (один файл `Index.html`) плюс логика
(`Code.gs`). Чтобы получить настоящее приложение для телефона, страницу
**заворачивают в оболочку**. Внутри — тот же экран, снаружи — обычное
приложение: значок на рабочем столе, работает без интернета, есть
уведомления и доступ к файлам.

Оболочка называется **Capacitor**. Она бесплатная и делает ровно это.

Итог работы — **один файл `auron.apk`**. Его скачивают по ссылке и
устанавливают. Это и есть ваше приложение.

---

## Путь А. Без Android Studio — собирает GitHub (рекомендую)

Вам не нужно ничего устанавливать на компьютер. Сборку делает GitHub
бесплатно, по вашей команде.

**Как это выглядит в жизни:**

1. Я готовлю проект и настраиваю сборку (один раз).
2. Вы нажимаете кнопку на сайте GitHub — или я делаю правку, и сборка
   запускается сама.
3. Через 5–10 минут появляется готовый файл `auron.apk`.
4. Вы скачиваете его или отправляете ссылку людям.

**Плюсы:** ничего не ставить, ничего не настраивать, файл собирается
одинаково каждый раз.

**Минус:** нельзя мгновенно проверить правку на телефоне — надо
дождаться сборки.

---

## Путь Б. Android Studio у себя на компьютере

Нужен, если хотите **сами** собирать и сразу видеть результат.

### Что установить

1. **Android Studio** — с сайта developer.android.com, бесплатно.
   Установщик сам поставит всё нужное (Android SDK, Java).
   Размер большой: около 8–12 ГБ на диске.
2. **Node.js** — с сайта nodejs.org, версия LTS.

### Порядок работы

```
1. Открыть папку проекта в командной строке
2. npm install                     ← ставит Capacitor (один раз)
3. npx cap add android             ← создаёт Android-проект (один раз)
4. npx cap sync                     ← переносит нашу страницу в проект
5. npx cap open android             ← открывает Android Studio
6. В Android Studio: Build → Build APK
```

Готовый файл появится в
`android/app/build/outputs/apk/debug/app-debug.apk`.

### Проверить на своём телефоне

- подключить телефон проводом;
- включить на телефоне «Отладка по USB» (Настройки → Для разработчиков);
- в Android Studio нажать зелёный треугольник «Run».

Приложение установится на телефон за минуту. Дальше любую правку видно
сразу — это главное преимущество этого пути.

---

## ⚠️ Самое важное во всём документе: ключ подписи

Приложение подписывается ключом. **Обновление устанавливается поверх
старого только если подписано ТЕМ ЖЕ ключом.**

Потеряете ключ — обновлять больше не сможете. Людям придётся удалить
приложение и поставить заново, **потеряв все данные**.

**Что делать:**

1. Создать ключ один раз (Android Studio: Build → Generate Signed
   Bundle/APK → Create new).
2. Записать пароль от ключа в надёжное место.
3. Хранить файл ключа **в трёх местах**, и одно из них — не дома
   (флешка у родственника, зашифрованный архив в облаке).

Это единственная вещь в проекте, которую нельзя восстановить никак.

## Как люди будут ставить приложение

Файл `apk` не из магазина, поэтому Android спросит разрешение:

1. человек открывает ссылку и скачивает файл;
2. Android говорит «установка из неизвестных источников запрещена»;
3. человек нажимает «Настройки» → разрешает для браузера;
4. установка идёт как обычно.

Один раз на телефон. Дальше обновления ставятся проще.

**Предупредите людей заранее** — иначе половина решит, что это вирус,
и не поставит.

---

## Как будут приходить обновления

Внутри приложения делается проверка: раз в сутки оно спрашивает у
GitHub, нет ли новой версии. Если есть — показывает: «Доступно
обновление, скачать?».

Человек нажимает, скачивается новый файл, ставится поверх. Данные
остаются на месте — при условии того самого ключа подписи.

## Резервная копия — как это работает

Так, как вы описали:

1. **Сделать копию.** Кнопка в настройках → файл `auron-2026-08-06.json`
   → отправить себе в WhatsApp, на почту или в Яндекс.Диск.
2. **Перенести.** На другом телефоне ставится то же приложение.
3. **Загрузить копию.** Кнопка «Загрузить копию» → выбрать файл.

**Важное правило, которое приложение будет говорить вслух:**
загрузка копии **ЗАМЕЩАЕТ** данные, а не добавляет к ним. Если на
втором телефоне уже что-то записано — оно сотрётся. Приложение спросит
подтверждение и назовёт, сколько записей будет потеряно.

Поэтому: **работаем на одном устройстве, второе — для просмотра.**

Копии будут делаться и **автоматически** — раз в день, без вашего
участия. Ручные копии люди не делают, а потерянный телефон уносит год
работы.
