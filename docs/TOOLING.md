# Инструменты Claude Code — что установлено

Список из ролика «24 штуки, которые стоит установить в Claude Code».
Установлено **на уровне проекта** — то есть работает у всех, кто открыл эту папку,
и в облачных сессиях тоже. Ничего доустанавливать вручную не нужно,
кроме одного скрипта и ключей (см. ниже).

## Плагины — 13 шт., стоят автоматически

Прописаны в `.claude/settings.json`, Claude скачивает их сам при запуске.

| Плагин | Что делает |
|---|---|
| `frontend-design` | интерфейс перестаёт выглядеть «по-ИИшному» |
| `superpowers` | сначала план и спека, потом код |
| `context7` | свежая документация библиотек вместо устаревшей памяти |
| `playwright` | сам открывает сайт, кликает, тестирует |
| `firecrawl` | вытаскивает данные с любого сайта |
| `supabase` | работа с базой и авторизацией |
| `telegram` | бот, канал, оповещения |
| `github` | код, версии, деплой |
| `notion` | база знаний и CRM |
| `hyperframes` | HTML → видео |
| `skill-creator` | сборка собственных навыков |
| `caveman` | режет болтовню, экономит токены |
| `claude-seo` | SEO-аудит |

## Навыки — 6 шт., лежат в репозитории

`ui-ux-pro-max` разложен по папкам в `.claude/skills/`:
`design`, `design-system`, `ui-styling`, `brand`, `banner-design`, `slides`.

## Навыки — gstack, ставится скриптом

57 навыков (планирование, ревью, QA, деплой). Весит 23 МБ, поэтому в git не кладём.

```bash
bash scripts/setup-claude-skills.sh
```

## MCP-серверы — 3 шт., нужны ключи

Прописаны в `.mcp.json`. Заработают, когда добавишь переменные окружения:

| Сервер | Что положить в переменные |
|---|---|
| `firecrawl` | `FIRECRAWL_API_KEY` — с firecrawl.dev |
| `n8n` | `N8N_API_URL`, `N8N_API_KEY` — со своего сервера n8n |
| `yandex-cloud` | `YANDEX_CLOUD_TOKEN`, `YANDEX_CLOUD_FOLDER_ID` |

Ключи в репозиторий **не кладём** — только имена переменных.

Остальные MCP (`github`, `notion`, `supabase`, `telegram`, `context7`, `playwright`)
приехали внутри плагинов и настраиваются при первом использовании.

## Чего установить не удалось

| Пункт | Почему |
|---|---|
| `bulletproof` | такого навыка не существует. Его роль (план → тесты → ревью → деплой) закрывают `superpowers` и `gstack` |
| `ЮKassa` | официального MCP-сервера нет, в npm пусто. Платежи подключаем обычным API |
| `anthropic/skills` | Word, Excel, PowerPoint, PDF уже встроены в Claude, отдельная установка не нужна |
| `marketing`, `productivity`, `dataviz`, `security-review` | это плагины и навыки уровня аккаунта claude.ai, включаются в настройках аккаунта, а не в проекте |

## Важное предупреждение

`yandex-cloud` — **неофициальный** сервер от стороннего разработчика
(`@theyahia/yandex-cloud-mcp`). Он получит доступ к твоей облачной инфраструктуре,
когда добавишь токен. Пока токена нет — сервер не работает и ничего не может.
Прежде чем давать ему токен, стоит выдать ключ с минимальными правами.

По той же причине не подключён ЮKassa: пускать непроверенный чужой код
к приёму платежей — плохая идея.
