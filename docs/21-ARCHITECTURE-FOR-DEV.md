# Архитектура Auron — для программиста

Ответ на вопрос «где сервер, где фронт, где бэк, всё ли на Timeweb».

## Короткий ответ: нет, на Timeweb почти ничего

Главное недоразумение, которое стоит снять сразу.

**Рабочая версия, которой пользуются каждый день, живёт целиком в
Google.** Timeweb куплен, там развёрнут Supabase — но приложение туда
не переехало. Это заготовка на будущее.

Если искать код на Timeweb — вы его не найдёте.

## 1. Что работает сегодня (единственная живая версия)

```
    ТЕЛЕФОН ВЛАДЕЛЬЦА                    GOOGLE
   ┌──────────────────┐         ┌────────────────────────┐
   │  браузер / PWA   │  HTTPS  │  Google Apps Script    │
   │                  │ ──────► │  (webapp/Code.gs)      │
   │  Index.html      │         │  329 функций           │
   │  один файл       │ ◄────── │                        │
   └──────────────────┘         │           ▼            │
                                │  Google Таблица        │
                                │  на диске ВЛАДЕЛЬЦА    │
                                └────────────────────────┘
```

| Слой | Что это | Где |
|---|---|---|
| **Фронтенд** | `webapp/Index.html` — один файл: вёрстка, стили, вся клиентская логика. Сборщика нет, Apps Script его не поддерживает | отдаётся Apps Script как HTML-шаблон |
| **Бэкенд** | `webapp/Code.gs` — 329 функций на JS (движок Rhino/V8 от Google) | Google Apps Script |
| **База** | Google Таблица, ~20 листов: БАЗА, СЧЕТА, СМЕНЫ, ДОЛГИ, ТОВАРЫ… | **Google Drive владельца магазина** |
| **Связь** | `google.script.run` — RPC поверх HTTPS, обёрнут в `gs()` в Index.html | — |

### Ключевое архитектурное решение

```json
"executeAs": "USER_ACCESSING"
```

Скрипт выполняется **от имени вошедшего пользователя**, а не от имени
разработчика. Следствия:

- таблица с деньгами лежит на Google Drive **клиента**, не у нас;
- разработчик физически не может прочитать чужие данные;
- у каждого магазина своя таблица — изоляция на уровне Google Drive;
- сотрудники получают доступ через `addEditor()` по email.

Это не случайность, а осознанный выбор: снимает с владельца
приложения статус оператора персональных данных. Обратная сторона
описана в `docs/18-AUDIT-MULTIUSER.md` — приглашённый сотрудник
технически видит все листы таблицы.

### Ограничения площадки (важно перед предложениями)

| Ограничение | Значение |
|---|---|
| Время одного вызова | 6 минут |
| Кэш (`CacheService`) | 100 КБ на ключ |
| Блокировка (`LockService`) | ожидание 20 сек |
| Версий деплоя | 200 |
| Сборщики, npm, модули | **нет** |
| `async/await`, ES-модули | нет, только ES5-совместимый код |

Отсюда монолитный `Index.html` на 14 000 строк — не небрежность, а
единственный доступный вариант.

## 2. Android-приложение (собрано, работает)

Тот же самый код, но **без Google вообще**.

```
   ТЕЛЕФОН
  ┌────────────────────────────────────────┐
  │  APK (Capacitor 6, WebView)            │
  │  ┌──────────────────────────────────┐  │
  │  │ Index.html   (тот же файл)       │  │
  │  │ Code.gs      (тот же файл)       │  │
  │  │ gas-bridge.js ← подменяет Google │  │
  │  │ localStorage ← вместо Таблиц     │  │
  │  └──────────────────────────────────┘  │
  └────────────────────────────────────────┘
        сервера нет · интернета не нужно
```

`android/gas-bridge.js` (~130 строк) выдаёт себя за `SpreadsheetApp`,
`CacheService`, `LockService`, `PropertiesService`. Логика из `Code.gs`
работает **без единой правки** — проверено запуском, см.
`webapp/tests/android-bridge.test.js`.

Сборка: `.github/workflows/build-apk.yml`, GitHub Actions, подпись
постоянным ключом из секретов репозитория.

открытым текстом. Записано в `handoff/06-KNOWN-ISSUES.md`.

## 4. Почему так вышло

Проект ведёт владелец магазина, не программист, вместе с ИИ.
Направление менялось несколько раз: Google Apps Script → Supabase на
своём сервере → приложение целиком на устройстве. Каждый заход оставил
рабочий слой, ни один не удалён.

Что из этого следует практически:

- **живое** — `webapp/` (Apps Script) и `android/`;
- **заготовки** — `app/`, `infra/`, `supabase/`, `server/`;
- **мёртвое** — `prototype/`, `local/`, `tools/`, `cloudflare/`.

## 5. Если спросят «что бы вы посоветовали»

Владельцу полезнее всего услышать мнение по трём пунктам:

1. **Разделить репозиторий.** Приложение, каталог товаров и заготовка
   на Supabase — три проекта в одном месте, в разных ветках. Сборка
   сайта однажды стёрла каталог, потому что собирает его из трёх веток
   сразу.
2. **Https на Timeweb** — домен и сертификат. Одно действие закрывает
   требование 152-ФЗ к защите данных и открывает push-уведомления.
3. **Стоит ли вообще переезжать с Apps Script.** Он медленный (2–6 сек
   на экран), но даёт то, что трудно повторить: данные лежат у клиента,
   а не у нас. Мнение со стороны здесь ценно.
