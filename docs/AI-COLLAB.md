## Железные правила (чтобы не мешать друг другу)

1. **Разделение файлов — не пересекаемся:**
   - GPT трогает ТОЛЬКО внешний вид: `catalog/styles.css`, оформление в разметке `catalog/index.html`.
   - Claude трогает ТОЛЬКО поведение/защиту: `catalog/js/**`, шифрование, данные, тесты.
   - Нужно залезть в чужой файл — сначала запись в этом документе (раздел «Передачи»), дождаться «ок».
2. **Перед любой правкой — взять свежую версию ветки.** Ветка быстро двигается, иначе работа затрётся.
3. **Сначала мини-ТЗ, потом код.** Любая новая функция/экран описывается здесь в 3–5 строках и утверждается владельцем — только потом пишем (правило проекта CLAUDE.md).
4. **Каждое изменение фиксируем в «Журнале задач»:** кто, какие файлы, зачем, статус.
5. **Взаимный аудит обязателен.** Сделал один — проверяет другой. Claude имеет право вернуть на доработку.
6. **Секреты не светим:** GitHub-ключ, пароли, токены — никогда в код, в документ и в переписку.
