# Тестовые архивы и восстановление — 17.10.2026

Развитие этапа 1: пользователь попросил продолжить разработку. В рабочей ветке добавлен ручной экспорт всей тестовой истории и восстановление в **отдельный новый файл**, без замены текущей SQLite. Это функциональность приложения, не настройка внешнего хранилища на компьютере владельца. На его сервере ничего автоматически не устанавливалось.

## Реализовано

- Раздел «Копии данных»: скачать JSON и проверить выбранный файл. Включены все смены и версии, а не ограниченный список экрана. Несохранённый ввод не входит. Подробные предупреждения о незашифрованных именах/суммах и необходимости отдельного носителя.
- Согласованный снимок в транзакции чтения. Формат/версия, дата, SHA-256, исходные строки, сохранённые результаты и таблица идемпотентности. Валидация пересчитывает каждую версию, проверяет связи и непрерывность; не принимает неизвестную формулу.
- Отдельная утилита restore.mjs: проверка → новая временная SQLite → сверка восстановленных строк → закрытие → атомарная публикация через hard link в новый файл. Существующий файл не перезаписывается. Автопереключения нет. Архив не содержит исполняемых SQL-команд.
- Явный флаг --recovered-test с абсолютным путём для просмотра восстановленной копии в том же локальном сервисе. Без флага используется прежняя тестовая база.
- Защита скачивания и проверки тем же Origin/Host/CSRF-контролем; это не пользовательская авторизация. Проверка архива через HTTP не изменяет рабочую базу.

## Границы

Формат ограничен 16 МиБ / 10 000 версиями: превышение даёт явную ошибку, обрезания нет. SHA-256 обнаруживает повреждение, но не подтверждает автора: подделка с пересчётом SHA возможна. Шифрование, расписание, внешнее хранилище, production-процедура восстановления и роли ещё не сделаны. Восстановление на Windows/NTFS и сбои питания на реальном устройстве требуют отдельного испытания. Не подключать незашифрованные архивы с реальными данными к публичному каталогу или ИИ.

## Проверки

47 тестов (9 новых для архива) на Node.js 24: 105 смен при лимите экрана 100, полный round-trip версий и повторов, повреждение, неверный расчёт/формула, дубли/пропуски/связи, отказ в непустую базу, сохранность существующего файла и очистка известной временной папки после отказа. Полный код не означает готовность магазина к эксплуатации.

Повторный прогон Chromium: 1440×1000, 390×844, 320×740. Проверены прежняя сверка/история/печать, новое скачивание настоящего JSON через браузер, выбор скачанного файла, успешная проверка и отказ при повреждённой SHA. Проверка не изменила активную базу. В этих сценариях ошибок JavaScript и горизонтального переполнения не обнаружено. Скриншоты изучены; Windows, физический принтер и Safari/Android не испытаны.
