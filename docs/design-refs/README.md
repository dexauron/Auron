# Что нравится владельцу — образцы дизайна

Сюда складываем картинки, которые владелец присылает как «мне нравится вот
так». Не для копирования: для сверки. Перед тем как делать экран, я смотрю
сюда и проверяю, попадаю ли в его вкус.

**Как пополнять:** владелец присылает снимок прямо в переписку (самый
надёжный способ) или ссылку на Pinterest — тогда я скачиваю картинку сам.
Я кладу файл сюда и дописываю строку в таблицу ниже: что именно понравилось.

| Файл | Что это | Что владельцу понравилось |
|------|---------|---------------------------|
| `01-monex-mobile.webp` | Monex, финансовое приложение (Валерия Гуцу) | Тёмный фон, один яркий акцент, крупные цифры, круглые действия прямо в карточке баланса, нижняя панель с «+» посередине |
| `02-legierski-payments.jpg` | Mobile Payments (Filip Legierski) | **Расположение** блоков, а не цвета: карточка-баланс сверху, под ней две кнопки-таблетки «стрелка + подпись», список настроек переключателями, столбчатый график с выделенным столбцом, полоса лимита, переключатель Неделя/Месяц/Год, плавающая панель снизу |

## Что из этого уже перенесено в Auron

- Тёмный фон и один зелёный акцент — было изначально.
- Нижняя панель с круглой «+» посередине — есть.
- Крупные цифры с плотными межбуквенными — есть.
- Переключатель периодов — есть (Сегодня / Неделя / Месяц / Год / Свой).

## Что НЕ переносим и почему

Оба образца — приложения для ЛИЧНЫХ денег: пять цифр на экране, много
воздуха. Auron — рабочий инструмент: долги поставщикам, смены, 16 555
товаров, сверка с 1С. Их красота построена на пустоте; нам нужна красота
при плотности, а это другая задача. Слепо копировать просторность —
значит уместить три строки там, где владельцу нужно двадцать.
