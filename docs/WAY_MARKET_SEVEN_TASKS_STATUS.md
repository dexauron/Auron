# Way Market — остаток семи направлений

19.10.2026, TEST 0.5. Реестр выполнения, не обещание общей готовности. Предыдущее «могу закончить все 7» означает цель разработки, а не подтверждение завершения.

| Направление | Уже есть в рабочей области | Что ещё нужно для приёмки |
|---|---|---|
| 1. Доступ с устройств | Отдельный HTTPS-запуск, список разрешённых IP, Windows-скрипты сертификатов/ACL/firewall | Испытание на AURON-SERVER и телефонах, подтверждение изоляции гостевой сети, отдельное защищённое решение удалённого доступа |
| 2. Каталог | Ручные товары, штрихкод, розничная цена, ссылки товаров в заказах | Интеграция исходного каталога: фото, группы, упаковки, несколько штрихкодов, наличие, публичная проекция, список покупателя/WhatsApp |
| 3. Закупки | Поставщики → лимиты → заказы/резерв → частичная/финальная приёмка → разбор расхождений, версии/архив | Заявки, согласования, профили закупщика/кладовщика, автоматический перенос лимита, складской эффект, обязательства, возвраты/корректировки, договоры/вложения/претензии |
| 4. Финансы и персонал | Сдача кассира, независимый приём бухгалтером, расчёт разниц, история | Счета/журнал денег, платежи/долги, банк/сверка, расходы/подотчёт, табель/начисления/выплаты, связь приёмки с обязательством |
| 5. Кабинеты и согласования | Личные аккаунты, серверные роли, собственные кассы/задачи | Кабинет ТП с назначением поставщика, объектные и временные права, двухсторонние подтверждения, уведомления и согласования |
| 6. Импорт и аналитика | Отдельные проверяемые библиотеки импорта/расчётов в репозитории | Подключение в рабочую область, предпросмотр/сопоставление/дубли, реальные обезличенные образцы файлов 1С/Excel, определения отсутствующих KPI, отчёты и проверяемые рекомендации |
| 7. Эксплуатация | Локальные аккаунты/сеансы, ограничения входа, смена пароля, шифрованные копии и проверка восстановления, личные серверные черновики | Восстановление доступа владельца, управление устройствами, автозапуск с безопасным хранением секрета, обновление/откат, копия на отдельном носителе, Windows/Safari/нагрузочные испытания |

Ни одна строка не объявлена полностью закрытой. Тестовые сценарии подтверждают только перечисленное реализованное поведение. Остаток согласованного расширенного ТЗ описан в WAY_MARKET_MASTER_SPEC.md; семь направлений группируют его, но не заменяют.
