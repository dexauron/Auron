# Настройка каталога — 10 минут, один раз

Каталог хранит товары и фото в **отдельной бесплатной базе** (Supabase).
Эти шаги делаются один раз. Ничего платного нигде вводить не нужно.

## Шаг 1. Создать бесплатный проект

1. Открой **supabase.com** → кнопка **Start your project**
2. Войди через Google (проще всего) или создай аккаунт
3. Нажми **New project**:
   - **Name:** `waymarket-catalog`
   - **Database Password:** придумай и сохрани куда-нибудь (понадобится редко)
   - **Region:** Frankfurt (ближайший к нам)
4. Нажми **Create new project** и подожди 1–2 минуты, пока проект создаётся

## Шаг 2. Создать таблицы

1. В меню слева выбери **SQL Editor**
2. Открой файл `schema.sql` (лежит рядом с этой инструкцией), скопируй весь текст
3. Вставь его в большое поле и нажми **Run** (или Ctrl+Enter)
4. Внизу появится «Success» — готово, база создана вместе со стартовыми группами товаров

## Шаг 3. Создать свой админ-аккаунт

1. В меню слева выбери **Authentication** → вкладка **Users**
2. Нажми **Add user** → **Create new user**
3. Введи свой email и придумай пароль — это и будет вход администратора в каталоге
4. Поставь галочку **Auto Confirm User** (чтобы не подтверждать почту) → **Create user**

## Шаг 4. Скопировать два значения

1. В меню слева: **Settings** (шестерёнка) → **API**
2. Скопируй два значения:
   - **Project URL** — адрес вида `https://abcdefgh.supabase.co`
   - **anon public** ключ — длинная строка букв (это публичный ключ, он не секретный)

## Шаг 5. Отправить значения Клоду

Пришли оба значения в чат — я вставлю их в `catalog/js/config.js`, и каталог заработает.

(Или сам открой `catalog/js/config.js` и вставь их между кавычек.)

## Вход для сотрудников (цены и контакты поставщиков)

Цены поставщиков и их телефоны видны только после входа. Чтобы включить:

1. Выполни `ОБНОВЛЕНИЕ-2.sql` в **SQL Editor** (один раз; свой админ-аккаунт
   при этом автоматически останется главным)
2. **Authentication → Users → Add user:**
   - Email: `staff@waymarket.ru` (именно такой — приложение ждёт его)
   - Пароль: придумай **общий пароль магазина** — его скажешь сотрудникам
   - Галочка **Auto Confirm User** → **Create user**
3. Готово. Форма входа одна для всех — программа сама различает права по аккаунту:
   - **Сотрудник**: жмёт человечка справа вверху → вводит только пароль магазина →
     видит цены, историю цен и контакты. Изменять каталог не может — только смотреть
   - **Ты (админ)**: в той же форме вводишь свой пароль — при первом входе появится
     поле email, дальше устройство подставляет его само и даёт права администратора

Сменить пароль магазина: Authentication → Users → staff@waymarket.ru → Reset password.

## Продажи и «Ходовые товары»

1. Выполни `ОБНОВЛЕНИЕ-3.sql` в **SQL Editor** (после ОБНОВЛЕНИЕ-2)
2. В меню админа появится **«📈 Импорт продаж»**: загружай отчёт «Продажи» из 1С
   (Excel). Есть колонка с датой — разложится по дням само; нет — укажи дату файла
3. У всех вошедших появится **«🔥 Ходовые товары»**: сегодня / 7 дней / 30 дней /
   свой период

## Про общий аккаунт сотрудников

- Вход **запоминается на устройстве** и продлевается сам — пока сотрудник не нажмёт
  «Выйти из аккаунта»
- Через один аккаунт `staff@waymarket.ru` могут одновременно работать **десятки
  сотрудников** — у каждого телефона свой сеанс, друг другу не мешают
- Ничего дополнительно включать не нужно; главное НЕ включать в настройках Supabase
  опцию «Single session per user» (по умолчанию она выключена)
