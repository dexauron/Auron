☁️ Публикация на GitHub

Каталог для покупателей хранится бесплатно на GitHub — без сервера и без VPN. Чтобы приложение сохраняло его туда, нужно один раз вставить «ключ». Ключ хранится только на этом устройстве.

Где взять ключ? (2 минуты)
  1. Зайди на github.com под своим аккаунтом.
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  3. «Generate new token». Repository access → Only select repositories → выбери Auron.
  4. Permissions → Repository → Contents → Read and write.
  5. Срок (Expiration) — побольше (например 1 год).
  6. Generate → скопируй ключ (показывается один раз) → вставь сюда.

⬆ Импорт данных

Выбери любые файлы из 1С или Excel — каталог сам поймёт, что это: цены поставщиков, остатки, продажи, контакты или прайс-лист розничных цен — и загрузит.

Импорт из 1С

Файл 1 — отчёт «Цены поставщиков» (обязательный). Файл 2 — отчёт «Штрихкоды номенклатуры», если нужны все штрихкоды (необязательный). Товары объединяются по коду: существующие обновятся, фото не тронутся.

Поставщики (редактирование)

🔥 Ходовые товары

Импорт продаж из 1С

Отчёт «Продажи» (Excel) из 1С: товары и количество за период. Период программа берёт из шапки файла сама. Товары находятся по названию. Повторная загрузка того же периода просто обновит данные.

Импорт остатков из 1С

Отчёт «Остатки номенклатуры» (Excel): количество на складе, код, штрихкод, группа, розничная цена. Дату остатков программа берёт из файла. Товар находится по коду/штрихкоду/названию — остаток и розничная цена обновятся; новый товар создастся.

Импорт контактов поставщиков

Excel из 1С: справочник «Контрагенты» с колонками «Контрагент» (название) и «Номер телефона». Поставщик находится по названию; если его нет — создаётся. Телефон обновляется, если изменился.

🖼 Фото из Excel

Excel-файл, где в одной колонке — ссылка на фото (скопированная с любого сайта), а в другой — штрихкод, код или название товара. Программа найдёт товары (сначала по штрихкоду, потом по коду, потом по точному названию) и покажет у них это фото. Само фото никуда не загружается — показывается по ссылке.

🖼 Найти фото автоматически

Ищем фото товаров по штрихкоду и названию в открытых всемирных базах (продукты, косметика, бытовая химия, корма). Находятся в основном известные бренды. Фото, похожие на наш товар, сохраняются в каталог и видны всем. Товары без бренда (развес, игрушки и т.п.) в базах не найти — их лучше сфотографировать самим через 📷 в карточке товара.

Держи это окно открытым, пока идёт поиск. Останавливать и продолжать можно в любой день — прогресс сохраняется.

🔑 Пароль магазина

Общий пароль, по которому входят сотрудники. После смены все их устройства выйдут из системы — скажи новый пароль смене. Меняй его при увольнении сотрудника.
