Публикация на GitHub

Каталог для покупателей хранится бесплатно на GitHub — без сервера и без VPN. Чтобы приложение сохраняло его туда, нужно один раз вставить «ключ». Ключ хранится только на этом устройстве.

Где взять ключ? (2 минуты)
  1. Зайди на github.com под своим аккаунтом.
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  3. «Generate new token». Repository access → Only select repositories → выбери Auron.
  4. Permissions → Repository → Contents → Read and write.
  5. Срок (Expiration) — побольше (например 1 год).
  6. Generate → скопируй ключ (показывается один раз) → вставь сюда.

Ходовые товары

Найти фото автоматически

Ищем фото товаров по штрихкоду и названию в открытых всемирных базах (продукты, косметика, бытовая химия, корма). Находятся в основном известные бренды. Фото, похожие на наш товар, сохраняются в каталог и видны всем. Товары без бренда (развес, игрушки и т.п.) в базах не найти — их лучше сфотографировать самим через камеру в карточке товара.

Держи это окно открытым, пока идёт поиск. Останавливать и продолжать можно в любой день — прогресс сохраняется.
