# Свой браузер (для изучения чужих сайтов)

Прокси этой среды пропускает обычные программы (curl, node), но **сбрасывает
соединения самого Chromium**. Поэтому «зайти на сайт и посмотреть» обычным
Playwright нельзя: любой адрес даёт `ERR_CONNECTION_RESET`.

Здесь браузер в сеть не ходит вовсе. Chromium только рисует страницу, а каждый
его запрос перехватывается (`page.route`) и выполняется нашим каналом
`net.js` — через `CONNECT`-туннель к прокси, который тот разрешает.

```bash
NODE_EXTRA_CA_CERTS=/root/.ccr/ca-bundle.crt \
node .claude/tools/browse/browse.js /tmp/shots \
  magnit=https://magnit.ru/ lenta=https://lenta.com/
```

Печатает заголовок, текст и **вес страницы** (запросы и мегабайты) — по нему
удобно сравнивать чужие каталоги с нашим. Снимки экрана кладёт в указанную папку.

Проверено: `magnit.ru`, `lenta.com` открываются полностью. `5ka.ru` и
`samokat.ru` отдают 403 — у них своя защита от роботов, канал тут ни при чём.

**Если однажды перестанет работать:** первым делом проверь порт прокси —
он меняется между сессиями, поэтому берётся из `$HTTPS_PROXY` на лету, а не
записан в коде. Диагностика: `curl -sS "$HTTPS_PROXY/__agentproxy/status"`.
