# Auron — интеграции

Принцип **API-first**: всё, что делает приложение, доступно через REST. Даты ISO 8601,
суммы в копейках, ID — UUID. Стандартные форматы на входе и выходе.

## REST и API-ключи

- **REST** — PostgREST поверх PostgreSQL, доступ настраивается через RLS.
- **API-ключи per-organisation** — каждая интеграция получает ключ с нужными правами
  (`api_keys.permissions` JSONB), отзывается в настройках. Не один всемогущий ключ на всё.

## Вебхуки

При ключевых событиях (смена закрыта, выплата проведена, заказ получен) Auron делает POST на
подписанный адрес.
- `webhook_endpoints`: `url · events(JSONB) · secret_hash · is_active`.
- `webhook_deliveries`: лог каждой отправки — `status(pending|success|failed) · attempts ·
  response_code · response_body`.
- Подпись через `secret_hash` — принимающая сторона проверяет подлинность. События берём из
  шины (см. skill `auron-modules`).

## Отправка через мессенджеры — три уровня

| Уровень | Способ | Настройка | Автоматика |
|--------|--------|-----------|-----------|
| Базовый (сразу) | **Web Share API** — системный шейр: WhatsApp/Telegram/Viber/VK/SMS | нет | нет, жмёт пользователь |
| Полуавтомат | **wa.me / t.me ссылки** — открывает чат с готовым текстом | нет | нет |
| Полная авто | **Telegram Bot API** (официальный, бесплатный) | подключить бота | да |
| Полная авто | **WhatsApp Business API** (Meta, надёжно, сложная регистрация) | через Meta Business | да |
| Полная авто | **Green API** (неофиц. шлюз, популярен в РФ, через SIM в облаке) | ключ Green API | да |

Стратегия: **Web Share включён по умолчанию** — делиться отчётом можно с первого дня без
настройки. Автоотправка — апгрейд в настройках.

## Другие каналы

- **Zapier / Make** — владелец без программиста соединяет Auron с 6000+ сервисами (готовый
  Zapier App). Примеры: «итог дня → Google Sheets», «кассовый разрыв → письмо на Gmail».
- **Email-to-action** — уникальный адрес per-org `invoice-{uuid}@auron.app`: переслал
  накладную → ИИ читает → долг создаётся.
- **Deep links** — `auron://suppliers/ivanov` из WhatsApp/QR открывает нужный экран
  (Universal Links iOS + App Links Android).
- **CSV / JSON импорт-экспорт** — стандартные форматы, не только Excel.
- **SMS** (SMS.ru / SMSC) — запасной канал, платно. **QR-коды** — на любом объекте.

## Безопасность (см. skill `auron-security-antipatterns`)

- Токены интеграций — в зашифрованных полях, не в коде и не в аудите.
- Вебхуки — с проверкой подписи. API-ключи — с узкими правами и возможностью отзыва.

## Чек-лист новой интеграции

- [ ] Данные наружу — в стандартном формате (ISO 8601, копейки, UUID)
- [ ] Событие берётся из шины, не из прямого вызова модуля
- [ ] Ключ/токен с минимальными правами, хранится зашифрованно, отзывается
- [ ] Вебхук подписан `secret_hash`, отправки логируются в `webhook_deliveries`
- [ ] Для владельца есть простой путь (Web Share / кнопка), автоматика — как апгрейд
