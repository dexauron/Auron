# Auron — деньги, даты, числа

Маленький, но критичный скил: одна ошибка здесь тихо портит все финансовые цифры.

## Деньги — копейки (bigint)

- В БД и в вычислениях **все суммы — целые копейки** (`*_kopecks`, bigint). Никогда float.
- **Деление на 100 — только в момент показа** пользователю. В логике считаем в копейках.
- Валюта — RUB. Округление — на уровне копеек, до отображения не округлять рубли.

```
хранение/расчёт:  1550000  (копейки)
на экране:        «15 500,00 ₽»  или  «15 500 ₽»
```

## Отображение по-русски

- Разделитель тысяч — пробол (неразрывный): `15 500 ₽`.
- Дробная часть — запятая: `15 500,50 ₽`. Часто копейки при показе можно скрыть, если ноль.
- Символ рубля `₽` после суммы с пробелом. Владелец — не программист, форматируй как в
  привычных российских приложениях.

## Даты — ISO 8601 в данных, по-русски на экране

- Хранение и API — **ISO 8601** (`2026-07-29`, `2026-07-29T14:32:00Z`).
- Показ — привычный формат: `29 июля 2026`, `29.07.2026`, `14:32`.
- Часовой пояс организации — в `organizations.settings.timezone`. Учитывать при показе смен,
  «ночная смена» настраивается через `night_shift_date(start|end)`.

## ID — UUID

Идентификаторы — UUID везде. Операции ввода несут `client_uuid` для идемпотентности.

## Проценты и коэффициенты

- Целевая маржа — `organizations.settings.target_margin_percent`.
- Коэффициенты табеля — 0.00–1.00 (`timesheet_entries.coefficient`).
- Считать в исходных единицах, форматировать при показе.

## Чек-лист

- [ ] Сумма хранится/считается в копейках (bigint), не во float и не в рублях
- [ ] Деление на 100 только при отображении
- [ ] На экране — русский формат: пробел-разделитель, запятая, `₽`
- [ ] Дата в данных — ISO 8601, на экране — привычный русский вид
- [ ] Учтён `timezone` организации, где это важно
