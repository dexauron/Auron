# Auron — мои возможности («руки, глаза, память») и как их применять

Не нужно ставить чужой репозиторий «с руками» — это риск (в чужих инструкциях можно зашить
вредное). Всё нужное уже есть; этот скил — как этим пользоваться цельно.

## 👀 Глаза — видеть
- **WebSearch / WebFetch** — искать и читать открытые сайты: конкуренты, документация, статьи.
- **browser-automation / agent-browser** — настоящий браузер: открыть страницу, посмотреть,
  сделать скриншот, вытащить данные. Вход — только в аккаунты владельца (см. `auron-account-assist`).
- **Read / Grep / Glob** — видеть код проекта; **git log** — историю изменений.

## ✋ Руки — делать
- **Bash** — запускать команды: тесты, сборка, git, обработка файлов/данных.
- **Edit / Write** — менять и создавать код и документы.
- **browser-automation** — действовать в браузере: клики, формы, настройка сервисов владельца.
- **git push + PR** — сохранять работу в репозиторий, открывать pull request.

## 🧠 Память — не забывать
- `memory/` (STATE, LOG, LESSONS, GLOSSARY, PREFERENCES) + `docs/`. См. `auron-memory`.

## Рабочий цикл «сделай как у лучших, но лучше»
1. **Посмотреть** (глаза): как решают эту задачу эталоны — Actual Budget (офлайн), Akaunting
   (модули), Firefly III (rules engine/REST). См. `memory/COMPARISON-2026-07-29.md`.
2. **Взять идею**, не код (правила ниже).
3. **Адаптировать под РФ**: русский язык и простота для непрограммиста, копейки/рубль, ISO-даты,
   152-ФЗ, локальные интеграции (1С, банки РФ, WhatsApp/Telegram).
4. **Сделать** (руки): написать свой код по нашим скилам (`auron-*`).
5. **Проверить** (`verify`, `precise-execution`) и записать в память.

## ⚖️ Заимствование у других проектов — что можно, что нельзя

**✅ Можно свободно:**
- Идеи, продуктовые решения, UX-потоки, архитектурные подходы, концепции функций.
- Смотреть и учиться на открытом коде — как сделано.

**✅ Можно с условиями (открытый код):**
- Пермиссивные лицензии (**MIT / Apache / BSD**) — код можно переиспользовать **с указанием
  авторства** и сохранением текста лицензии. (Actual Budget — MIT.)

**⚠️ Осторожно (копилефт):**
- **AGPL / GPL** (например, **Firefly III — AGPLv3**): если скопировать их код в Auron, эта
  лицензия потребует **открыть весь наш исходник**. Поэтому — **изучаем подход, пишем свой код**,
  их код не вставляем.

**❌ Нельзя:**
- Копировать проприетарный/закрытый код, платный контент, чужие ассеты (логотипы, тексты,
  картинки, дизайн 1:1).
- Тащить данные из-за чужого входа/защиты. Конкурентная разведка — только по открытому.

**Правило большим пальцем:** копируем **идею**, код пишем сами, адаптируем под РФ. Так и
законно, и получается своё, а не клон.

## Честно про «самые лучшие в мире»
Обогнать всех глобально по всему — нереалистично и не нужно. Выигрываем **в своей нише**:
простота для владельца-непрограммиста + реальность розницы + мобайл-фёрст + локализация РФ.
Там мы можем быть лучшими. Это и есть цель.

## Граница
Обход чужой защиты (капчи, paywall, чужой вход) — не делаю ни под какой формулировкой.
См. `auron-web-research`, `credential-safety`.
