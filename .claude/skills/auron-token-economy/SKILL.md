# Auron — экономия токенов и точность

Auron — это `app/index.html` на ~7000 строк и документы `docs/` до ~970 строк. Читать их
целиком без нужды = сжечь тысячи токенов и утопить в них суть. Дисциплина ниже даёт
экономию в разы и одновременно повышает точность (меньше шума → меньше ошибок).

## Правила поиска (сначала найди, потом читай)

1. **Grep/Glob вместо чтения файла целиком.** Нужна функция `closeShift` — `Grep` по имени,
   прочитать 30–60 строк вокруг, а не весь `index.html`.
2. **Читай диапазонами.** `Read` с `offset`/`limit` по найденным строкам. Целиком — только
   если файл реально маленький или нужен весь.
3. **Документы — по оглавлению.** В `docs/*` сначала найди нужный раздел Grep-ом
   (например `## Синхронизация`), читай его, а не файл от корки до корки.
4. **Схема БД — точечно.** В `docs/05-ARCHITECTURE.md` таблицы сгруппированы по доменам.
   Ищи нужную таблицу по имени, не читай все 76.

## Правила записи (не раздувай контекст)

5. **Не перечитывай файл после своей правки.** Edit/Write упадёт, если правка не удалась —
   повторное чтение ради проверки не нужно.
6. **Точечный Edit вместо переписывания.** Меняешь одну функцию — правь её, не переписывай
   весь файл.
7. **Большие данные — в scratchpad, не в контекст.** Промежуточные списки, дампы, выгрузки
   пиши в файл scratchpad и работай с ним через Grep, а не держи в переписке.
8. **Параллель.** Независимые чтения/поиски запускай одним пакетом, не по очереди.

## Правила ответа владельцу

9. **Коротко и по делу.** Владелец — не программист. Ответ = что сделал + результат, без
   пересказа каждого шага и без стен кода, которые он не просил.
10. **Не дублируй уже сказанное.** Не пересчитывай заново то, что уже установлено в разговоре.

## Быстрый ориентир по коду

```
app/index.html   — SPA-каркас (~7000 строк) — искать, не читать целиком
app/js/api.js    — все запросы к базе (query-builder _q, _rpc)
app/js/auth.js   — авторизация, PIN
app/sw.js        — Service Worker, версия кэша auron-vNN
docs/            — источник истины по решениям; читать нужный раздел
```

## Чек-лист перед крупным чтением

- [ ] Я точно не найду это быстрее через Grep/Glob?
- [ ] Мне нужен весь файл или хватит диапазона?
- [ ] Не читаю ли я то, что уже есть в контексте?
- [ ] Большой промежуточный результат — не положить ли в scratchpad?
