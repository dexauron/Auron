# Каталог товаров для магазина

Готовый каталог для небольшого магазина. **Сервера нет и платить не за что:**
и сайт, и данные живут на GitHub бесплатно. Товары загружаются обычными
выгрузками из 1С в Excel.

У каталога два зала:

**Покупателю** (просто открыл ссылку) — название, код, цена, есть ли в
наличии, когда привезли, описание. Можно собрать список покупок и отправить его
в WhatsApp кому угодно, подсказать магазину цену из другого магазина, оценить
товар, попросить сообщить, когда товар появится.

**Сотруднику и владельцу** (ввёл пароль) — закупочные цены по поставщикам с
историей, остатки, подсказка «сколько заказать», заказы поставщикам с
календарём, список «закончилось на полке», сторож наценки, «подорожало»,
«залежалось», ходовые товары, сравнение товаров, цены других магазинов.

Ещё: поиск по названию, коду и штрихкоду (понимает опечатки и латиницу),
сканер камерой — в том числе этикеток с весов, работа офлайн, установка на
главный экран телефона.

## Как сделать свой

**Не программист?** Откройте **[НАСТРОИТЬ-С-ПОМОЩЬЮ-ИИ.md](НАСТРОИТЬ-С-ПОМОЩЬЮ-ИИ.md)** —
там текст, который нужно скопировать в любой ИИ, и он всё настроит, задавая вам
вопросы.

**Программист?** Всё, что отличает один магазин от другого, — в одном файле
`js/config.js`. Полный путь на полчаса — в
**[КАК-СДЕЛАТЬ-СВОЙ-КАТАЛОГ.md](КАК-СДЕЛАТЬ-СВОЙ-КАТАЛОГ.md)**.

Коротко:

1. Нажмите **Use this template** → создастся ваша копия.
2. **Settings → Pages**: ветка `main`, папка `/`. Адрес сайта появится там же.
3. Поправьте `js/config.js` (название, цвет, контакты, ваш логин на GitHub).
4. Сделайте ключ GitHub (Settings → Developer settings → Tokens classic, право
   `repo`) и вставьте его в каталоге: меню → «Публикация на GitHub».
5. Войдите — **первый введённый пароль станет паролем владельца**.
6. Меню → «Загрузка из 1С» → выберите файлы выгрузок.

## Что внутри

Чистый JavaScript без сборщиков и зависимостей: 29 модулей в `js/modules/`,
одна страница `index.html`, одни стили `styles.css`. Открытая витрина — обычные
JSON-файлы в `data/`; закрытая часть зашифрована (AES-GCM), ключ лежит в
«конвертиках» под каждым паролем, поэтому смена пароля отключает прежнего
сотрудника.

Есть набор проверок (Playwright): `node tests/run.js` при поднятом
`python3 -m http.server 8123`. Они держат планку по скорости на бюджетном
Android, по вёрстке на узком экране и по приватности — что именно попадает в
открытую витрину.
