# Настроить каталог с помощью ИИ

Этот файл нужен, если вы не программист. Откройте любой ИИ (ChatGPT, Claude,
Gemini, Алиса — любой), скопируйте в него текст из серой рамки ниже **целиком**
и дальше просто отвечайте на вопросы. ИИ сам заполнит настройки и скажет, что
нажимать.

Если вы программист — вам хватит `js/config.js` и `КАК-СДЕЛАТЬ-СВОЙ-КАТАЛОГ.md`.

---

## Скопируйте это в ИИ

```
Ты помогаешь мне настроить готовый каталог товаров для моего магазина.
Я не программист, объясняй простыми словами, без технических терминов.

Что это за каталог. Это сайт-приложение для магазина, который работает БЕЗ
сервера: и сайт, и данные лежат на GitHub бесплатно. У него два зала. Кто
зашёл по ссылке без пароля — покупатель: он видит название товара, код, цену,
есть ли в наличии и когда привезли, может собрать список покупок и отправить
его в WhatsApp. Кто ввёл пароль — сотрудник или владелец: ему открываются
закупочные цены, остатки, поставщики, заказы, наценка и отчёты. Товары
загружаются выгрузками из 1С в Excel.

Всё, что отличает один магазин от другого, лежит в ОДНОМ файле: js/config.js.
Больше в коде менять нечего.

ТВОЯ ЗАДАЧА — два шага.

ШАГ 1. Задай мне вопросы по одному, не все сразу, и дождись ответа:
  1. Как называется магазин? (пойдёт в шапку и на вкладку браузера)
  2. Какая подпись под названием? Предложи «Каталог товаров», если не знаю.
  3. Какой основной цвет? Можно словами («тёмно-зелёный») — переведи сам в
     шестнадцатеричный код вида #1B7A3D.
  4. Есть ли логотип картинкой? Если нет — скажи, что вместо него покажется
     кружок с первой буквой названия, и это нормально.
  5. Нужен ли талисман — картинка-помощник, которая здоровается и подсказывает
     на пустых экранах (кот, медвежонок, что угодно)? Объясни, что это
     необязательно и без него каталог работает так же. Если я захочу — скажи,
     какие две картинки подготовить (во весь рост и только голову, PNG с
     прозрачным фоном) и как его назвать в настройках.
  6. Это продуктовый магазин? Если да — оставляем CATEGORIES: 'grocery',
     каталог сам разложит товар по 13 понятным разделам. Если нет — 'none',
     разделами станут мои группы из 1С.
  7. Что из этого мне нужно: цены других магазинов, отчёт «Ходовые товары»,
     остатки и подсказка «сколько заказать»? Ненужное выключим.
  8. Телефон, WhatsApp, адрес и часы работы — их увидит покупатель. Любое
     можно не указывать. ВАЖНО: предупреди меня, что эти данные станут
     видны всем, у кого есть ссылка.
  9. Мой логин на GitHub и как будет называться мой репозиторий.

ШАГ 2. Когда ответы собраны:
  — выдай мне ГОТОВЫЙ файл js/config.js целиком, чтобы я просто заменил им
    тот, что есть, ничего не дописывая руками;
  — напиши, какое название вписать в файл manifest.webmanifest (это имя,
    под которым каталог встанет на главный экран телефона);
  — дальше проведи меня по шагам из файла КАК-СДЕЛАТЬ-СВОЙ-КАТАЛОГ.md:
    включить сайт на GitHub Pages, сделать ключ публикации, первый вход,
    загрузка товаров из 1С, пароль для сотрудников.

ЧЕГО ДЕЛАТЬ НЕ НАДО:
  — не трогай ничего, кроме js/config.js и manifest.webmanifest;
  — не придумывай за меня данные магазина: не знаешь — спроси;
  — не проси у меня ключ GitHub и никуда его не вписывай: он хранится
    только на моём устройстве, в файлы его класть нельзя;
  — не обещай, что каталог что-то считает из 1С, пока я не загрузил выгрузки.

Начни с первого вопроса.
```

## Что важно знать до начала

**Ссылка публичная.** Каталог открывается без пароля — значит названия, коды,
штрихкоды и цену с полки видит любой, кому вы дали ссылку. Так и задумано: это
то же, что человек увидит, дойдя до полки. **Закупочные цены, остатки числом,
поставщиков и продажи без пароля не видно никогда.**

**Ключ публикации — это пароль.** Он хранится только в памяти вашего телефона
или компьютера. Не пересылайте его в переписке и не вставляйте в файлы.

**Первый введённый пароль становится паролем владельца.** Восстановить его
некому: сервера нет. Запишите.

**Данные обновляются раз в день.** Вы выгружаете из 1С и публикуете — обычно
вечером. Каталог честно пишет, когда данные обновились.
