# Как сделать такой же каталог для своего магазина

Каталог работает в двух залах сразу: кто открыл ссылку без пароля — покупатель
(название, код, цена, наличие, список покупок), кто ввёл пароль — сотрудник или
владелец (закупка, остатки, заказы, наценка). Сервера нет, платить не за что: и
сайт, и данные живут на GitHub бесплатно.

Всё, что отличает один магазин от другого, лежит в **одном файле** —
`js/config.js`. Ниже — весь путь, примерно на полчаса.

Не хотите читать — откройте `НАСТРОИТЬ-С-ПОМОЩЬЮ-ИИ.md`: там текст для любого
ИИ, он спросит про магазин и заполнит настройки сам.

## Что понадобится

- Аккаунт на github.com (бесплатный).
- Выгрузка из 1С в Excel — отчёт «Цены поставщиков». Остальные отчёты
  (штрихкоды, остатки, продажи) можно добавить потом.
- Телефон или компьютер с браузером.

## Шаг 1. Сделать свою копию

На странице этого репозитория нажмите **Use this template → Create a new
repository** — получится ваша копия со всем кодом и без чужой истории. Дальше
вы правите только свою копию.

## Шаг 2. Включить сайт

В своей копии: **Settings → Pages → Source: GitHub Actions**. Сохраните.
Через минуту-две сайт соберётся сам, адрес появится там же — он будет вида
`https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Шаг 3. Поменять настройки магазина

Откройте `js/config.js` прямо на сайте GitHub (карандашик) и поменяйте:

```js
STORE_NAME: 'Стройдвор',              // ваше название
STORE_SUBTITLE: 'Каталог для зала',   // подпись под названием
LOGO: 'icons/logo.png',               // ваш логотип: положите файл в icons/; пусто '' — будет первая буква названия
ACCENT: '#B3261E',                    // цвет кнопок

CATEGORIES: 'none',                   // 'grocery' — продуктовый магазин, 'none' — разделы из групп 1С
FEATURES: {
  competitors: false,                 // цены других магазинов — нужны? да/нет
  sales: true,                        // «Ходовые товары» из отчёта продаж
  stock: true,                        // остатки и подсказка «сколько заказать»
},

GITHUB_OWNER: 'ВАШ-ЛОГИН',            // ваш логин на GitHub
GITHUB_REPO: 'ИМЯ-РЕПОЗИТОРИЯ',       // название вашей копии
GITHUB_BRANCH: 'main',                // ветка, где будут лежать данные
DATA_PATH: 'data',                    // папка с данными — менять не нужно
```

Если у вас **продуктовый магазин** — оставьте `CATEGORIES: 'grocery'`: каталог
сам разложит товар по 13 понятным разделам (молочное, хлеб, напитки и так
далее), даже если в 1С группы заполнены криво. Для любого другого магазина
поставьте `'none'` — разделами станут ваши группы из 1С как есть.

Заодно поменяйте название в файле `manifest.webmanifest` — оно
показывается, когда каталог ставят на главный экран телефона.

## Шаг 4. Сделать ключ для публикации

GitHub → **Settings → Developer settings → Personal access tokens → Tokens
(classic) → Generate new token**. Право нужно одно: **repo**. Скопируйте ключ —
он показывается один раз.

⚠️ Ключ — как пароль от вашей копии. Он хранится **только на вашем телефоне**,
в каталог и в репозиторий не попадает. Никому его не пересылайте.

## Шаг 5. Первый вход

Откройте свой каталог, нажмите значок входа → меню → **«Публикация на GitHub»**
→ вставьте ключ → «Сохранить и проверить».

Затем войдите паролем: **первый введённый пароль становится паролем каталога**.
Запомните его — без него каталог не открыть, восстановить некому.

## Шаг 6. Загрузить товары

Меню → **«Загрузка из 1С»** → выберите файлы отчётов. Каталог сам поймёт, что
это за файл, соберёт товары, группы, поставщиков и цены, а потом опубликует.
Первая публикация большого каталога занимает несколько минут — дальше правки
уезжают за секунды, потому что переписываются только изменившиеся куски.

## Шаг 7. Дать доступ сотрудникам

Меню → **«Пароль сотрудника»** → задайте пароль и сообщите его сотрудникам.
Ссылка одна и та же для всех: без пароля видны названия, коды и цена с полки;
с паролем — закупочные цены, остатки, продажи и контакты поставщиков.

**Уволился сотрудник** — поменяйте пароль сотрудника в том же меню. Каталог
перешифруется целиком, и старый пароль перестанет открывать данные.

## Что дальше

- Фото товаров: каталог умеет искать их по штрихкоду в открытых базах
  (меню → «Фото»), остальное можно добавить вручную в карточке товара.
- Правила заказа (срок доставки, периодичность, страховой запас) — меню
  → «Правила заказа»; от них считается подсказка «сколько заказать».
- Каталог работает офлайн: один раз открыл — дальше ищет и без интернета.

## Если что-то пошло не так

| Что видно | Что делать |
|-----------|------------|
| «Пароль не подошёл» | Проверьте раскладку; пароль каталога задаётся при первом входе и восстановлению не подлежит |
| Каталог пустой | Не прошла публикация: проверьте ключ в меню «Публикация на GitHub» |
| Сайт не открывается | Settings → Pages: источник должен быть **GitHub Actions**; посмотрите вкладку Actions — там видно, собрался ли сайт |
| Изменения не видны | Закройте и откройте каталог заново — приложение обновляется при новом открытии |
