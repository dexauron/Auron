# memory/ — рабочая память Claude по проекту Auron

Это «второй мозг» в репозитории: то, что нужно помнить между сессиями и не держать в голове.
Пережитает перезагрузки, сжатие контекста и большой объём данных — потому что лежит в файлах.

## Как устроено (два уровня)

1. **`CLAUDE.md`** (корень репо) — постоянные правила проекта, читаются всегда.
2. **`memory/`** (эта папка) — живая память, обновляется по ходу работы.
3. **`docs/`** — утверждённые решения по продукту (формальная память проекта). Память здесь
   её не заменяет, а дополняет рабочими заметками.

## Файлы

| Файл | Что внутри | Когда обновлять |
|------|-----------|-----------------|
| `STATE.md` | Снимок текущего состояния: этап, что сделано, что дальше, ключевые факты | В конце каждой сессии и при смене этапа |
| `LOG.md` | Журнал сессий: коротко что делали (новое сверху) | В конце каждой сессии |
| `LESSONS.md` | Ошибки и уроки — чтобы не повторять | Как только что-то пошло не так или нашлось важное |
| `GLOSSARY.md` | Термины и сокращения владельца | Встретил новый термин — записал |
| `PREFERENCES.md` | Как владелец хочет, чтобы я работал и общался | Владелец высказал предпочтение |

## Протокол (обязателен — см. skill `auron-memory`)

- **Начало сессии:** прочитать `STATE.md`, при необходимости — остальное.
- **Во время работы:** новое важное решение → в `docs/DECISIONS.md`; урок/ошибка →
  `LESSONS.md`; новый термин → `GLOSSARY.md`.
- **Конец сессии:** обновить `STATE.md` и добавить строку в `LOG.md`.
- **Кратко.** Память нужна, чтобы быстро сориентироваться, а не перечитывать роман. Раздутый
  файл = потерянное время (принцип из skill `auron-token-economy`).

Владелец — не программист, но эти файлы человекочитаемые: он тоже может открыть и понять.
