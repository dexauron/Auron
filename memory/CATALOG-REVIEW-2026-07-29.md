## Вердикт
**Каталог в заметно лучшей форме, чем было приложение Auron.** Многое, что в Auron я
чинил, здесь уже сделано правильно. Критичных проблем не нашёл.

## Что сделано хорошо
- **HTTPS backend** уже есть (`https://104-171-136-141.sslip.io`, сертификат на IP через
  sslip.io) — проблемы mixed content, как у Auron, НЕТ.
- **RLS защищает секреты:** закупочные цены (`catalog_prices`) и контакты поставщиков
  (`catalog_supplier_contacts`) читаются только вошедшим с ролью закупок
  (`catalog_can_purchase()`, у anon отозвано). Публичный anon-ключ безопасен.
- **XSS-дисциплина есть:** функция `esc()` применяется, включая свободный текст (имя
  поставщика `esc(e.sup.name)`). 83 innerHTML, но подстановки экранируются.
- **Крипто по учебнику:** экспорт секретов шифруется AES-GCM 256 + PBKDF2 **150 000**
  итераций (Web Crypto), пароль не хранится — на GitHub только шифртекст (.enc).
- **Секретов в репозитории нет:** JWT/SERVICE_ROLE генерируются на сервере
  (`server-install.sh`, openssl rand) или читаются из локального .env; `service_role`
  на клиенте отсутствует. GitHub-токен — только в localStorage владельца.
- **Service Worker продуман:** «сначала сеть» для оболочки (всегда свежая онлайн, офлайн —
  копия) + отдельный вечный кэш фото товаров. Бампать версию не нужно (network-first).
- **Бесплатный статический режим:** покупатель без входа читает витрину из
  `data/products.json` (GitHub Pages, без сервера/VPN); секреты в этот файл не попадают.

## Мелкие замечания (не критично)
1. **Имена поставщиков публичны:** `catalog_suppliers` select using(true) — список
   поставщиков виден anon (цены и контакты — нет). Если не задумано, ужесточить.
2. **Инфраструктура хрупкая:** домашний сервер + Cloudflare-туннель + sslip.io + запасной
   прокси v2rayA. Работает, но аптайм зависит от домашнего канала. Для бизнеса — либо
   более надёжный хостинг, либо опираться на статический режим GitHub Pages как резервный.
3. **Проверить статический экспорт:** убедиться разово, что `products.json` не содержит
   закупочных цен/поставщиков (код это подразумевает — стоит подтвердить).
