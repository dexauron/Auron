# GLOSSARY — термины и сокращения проекта Auron

Расшифровка внутреннего языка, чтобы понимать владельца как коллега. Пополняется по мере.

| Термин | Значение |
|--------|----------|
| **Way Market** | Розничная сеть-пример, на которой обкатывается v1.0 (модуль розницы) |
| **Иман** | Хозрасходы владельца — выплата с кассы `type=iman`; категорию владелец задаёт сам (по умолч. «Хозрасходы владельца») |
| **Z-отчёт / смена** | `shifts` — закрытие кассовой смены: Z-суммы (нал/карта/СБП) vs факт, расхождение |
| **Кассовый разрыв** | Ситуация нехватки денег на обязательные выплаты; отслеживается как риск |
| **Финансовый пульс** 🟢🟡🔴 | Дневная оценка здоровья бизнеса (0–100): выручка/долги/накопления/расхождения с весами |
| **Сторно** | Обратная проводка, которой исправляют ошибку (реестр не редактируется) |
| **ТП** | Торговый представитель = поставщик (`suppliers`) |
| **Двойная запись** | Каждая операция = дебет + кредит, суммы равны (бухгалтерский стандарт) |
| **Фискальный период** | Месяц; после `closed`/`locked` записи не меняются |
| **org_id** | Идентификатор магазина-организации; по нему RLS изолирует данные |
| **Роли** | Владелец / Бухгалтер / Администратор / Сотрудник зала. «Кассира» нет |
| **Модуль** | Отдельная функция (Касса, Поставщики, Персонал, Товары, ИИ), включается per-store |
| **Шина событий** | Механизм, через который модули общаются (`shift.closed`, `debt.added`, …) |
| **auron-vNN** | Имя версии кэша в `sw.js`; бампается при каждом изменении фронта |
| **152-ФЗ** | Закон о персональных данных РФ; данные хранятся в России |
