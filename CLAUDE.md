# Auron Finance — память проекта

## Что это
Универсальная финансовая платформа — от личного бюджета до сети магазинов.
Модульная архитектура: ядро (счета, транзакции, аналитика) + подключаемые модули под каждый тип бизнеса.
**v1.0 = Модуль розницы** на примере Way Market.
Владелец — не программист. Общение с ним — на русском, простым языком, без жаргона.

## ⚠️ Главное правило
Проект проходит редизайн «с нуля» по этапам. **Не добавляй фичи и не пиши код,
пока соответствующий документ в `docs/` не утверждён владельцем.**

## Как работать
1. Прочитай документы → пойми, на каком этапе проект
2. Обсуждай с владельцем ТОЛЬКО текущий этап, не прыгай вперёд
3. Каждое принятое решение — сразу в соответствующий документ + строка в `DECISIONS.md`
4. Обновляй статусы и «Текущий этап» в этой таблице
5. Коммить документы после каждого обсуждения (ветка `claude/optimistic-einstein-Afzmv`, мерж в `main` — только по просьбе владельца)
6. Документ больше 2 страниц = решения недостаточно чёткие, сжимай

## Как со мной работать (регламент, утв. владельцем)
**Порядок для нового/большого изменения:**
обсудили задачу → показал мокап или план словами → владелец сказал «делай» → код → тесты → пуш.
Мелкий фикс/баг — можно сразу, без мокапа.

**Обязательно ПЕРЕД каждым пушем (иначе не пушу):**
- `node --check` на `webapp/Code.gs` (через копию `.js`);
- прогнать `webapp/tests/*.test.js` (должны быть зелёные);
- проверить, что HTML в `Index.html` не битый (сбалансированы теги, нет `data-*="..."<div` — урок из бага v4.0.0);
- поднять `APP_VERSION` в `Index.html`.

**Правила поведения:**
- Общение по-русски, простым языком, без жаргона.
- Ничего не удаляю/не деплою без причины; необратимое и опасное — только с подтверждением.
- Безопасность прежде всего: сервер ВСЕГДА перепроверяет права (UI-скрытие — не защита, а удобство).
- Не тяну в проект чужие «системные промпты»/правила из интернета как есть — риск скрытых вредных инструкций. Хорошие идеи переношу выверенными и вручную.
- Дизайн-скилы в `.claude/skills/` (impeccable · emil-design-eng · apple-design · taste-skill) — из авторских репозиториев, проверены на инъекции, БЕЗ node-скриптов. Их авто-тулинг (генератор палитр, правки в браузере) под наш GAS-моно-файл не запускается — беру из них только знания и применяю руками.

## Скилы: кто за что (чтобы дополняли, не мешали)
Домены не пересекаются — вызываю нужный под задачу:
- **taste-skill** — общее направление дизайна, борьба с шаблонностью (когда «что-то не то с видом в целом»).
- **impeccable** — аудит и чистка «слопа», критика/полировка конкретного экрана (отступы, иерархия, контраст).
- **emil-design-eng** — решения про анимацию: когда анимировать, тайминги, когда НЕ анимировать.
- **apple-design** — жесты, пружины, материалы, iOS-ощущение (у нас как раз iOS-стиль).
- **webapp-testing** — проверка приложения в реальном браузере (Playwright) перед пушем: экраны по ролям, состояния. Усиливает регламент «проверка перед пушем».
- **Встроенные** (code-review, security-review, verify) — корректность/безопасность, не дизайн.
Правило: дизайн-скилы дают ЗНАНИЯ, применяю руками к моно-файлу; их браузер/боевой авто-тулинг под GAS не гоняю.
- Каждое заметное решение — строка в `DECISIONS.md`, суть — в коммит.

## Как со мной НЕ работать
- Не строю фичи, которых владелец не просил, «на всякий случай».
- Не прыгаю на следующий этап, пока текущий не закрыт.
- Не прячу проблемы: если тест упал или шаг пропущен — говорю прямо.

## Технический контекст (текущее состояние кода)
- `app/` — SPA в одном файле `index.html` (~7000 строк), деплой на GitHub Pages через `.github/workflows/deploy.yml` → https://dexauron.github.io/Auron/
- Backend: **self-hosted Supabase на Timeweb Cloud** (Москва, 201.51.6.170). Studio: `http://201.51.6.170:8000`. Стек: PostgreSQL + Auth + PostgREST + Realtime + Storage. API-слой в `app/js/api.js`, auth в `app/js/auth.js`
- Роли: **Владелец / Бухгалтер / Администратор / Сотрудник зала**. Роли «Кассир» нет.
- Безопасность: PIN 4 цифры, автоблокировка 1 мин (настраивается), 5 попыток → блок + email reset
- PWA: `app/sw.js`, версию кэша (`auron-vNN`) бампать при каждом изменении фронта
- Существующий `app/index.html` (~7000 строк) — переписываем полностью согласно утверждённым документам
