# Запуск приложения (Google Apps Script)

Приложение работает на твоём Google-аккаунте: код — в Apps Script, данные — в
Google Таблицах, которые приложение **создаёт само на твоём Диске** при первом входе.
Никакой ID таблицы заранее вписывать НЕ нужно (модель «профиль на пользователя»).

## Что нужно
- Google-аккаунт
- Браузер на компьютере (для разворачивания) — 10 минут

---

## Шаги

### 1. Создать проект Apps Script
1. Открой [script.google.com](https://script.google.com)
2. **Новый проект**

### 2. Вставить код
1. В файле `Code.gs` — удали всё и вставь содержимое `webapp/Code.gs`
2. Слева **+ → HTML** → назови файл `Index` (ровно так, без расширения) → вставь содержимое `webapp/Index.html`

### 3. Вставить манифест (права доступа)
1. Слева ⚙ **Project Settings** → включи галочку **«Show appsscript.json manifest file»**
2. Открой появившийся `appsscript.json` → замени содержимое на `webapp/appsscript.json`

В нём уже прописано:
- `executeAs: USER_ACCESSING` — каждый работает под собой, данные на его Диске
- `access: ANYONE` — открывать по ссылке
- права: создавать только свои таблицы и файлы (`drive.file`)

### 4. Развернуть как веб-приложение
1. **Развернуть → Новое развёртывание**
2. Тип (шестерёнка): **Веб-приложение**
3. **Выполнять как:** *Пользователь, открывающий приложение*
4. **Доступ:** *Все* (или «Все, у кого есть аккаунт Google»)
5. **Развернуть** → **Разрешить доступ** → выбери аккаунт → пройди предупреждение Google («Дополнительно → Перейти к проекту») → разреши
6. Скопируй **ссылку веб-приложения**

### 5. Открыть на телефоне
1. Открой ссылку в браузере телефона, войди под своим Google
2. Зарегистрируйся (имя + название магазина) → приложение само создаст твои таблицы на твоём Диске
3. **iPhone (Safari):** «Поделиться» → «На экран Домой»
   **Android (Chrome):** меню ⋮ → «Установить приложение»

Готово — приложение на главном экране, как обычное.

---

## Что создастся на твоём Диске
- `Auron_Profile` — твой профиль и список магазинов
- `Auron_<название>` — отдельная таблица под каждый магазин (БАЗА, СЧЕТА, НАСТРОЙКИ…)

Всё это — на **твоём** Google. Никто другой это не видит.

---

## Для следующих знакомых
Каждый знакомый открывает **ту же ссылку** под своим Google и регистрируется —
его данные создаются на **его** Диске, отдельно от твоих. Отдельную копию делать не нужно.
(Полная копия с собственным кодом — отдельный шаг, делаем в самом конце.)

---

## Авто-обновление (чтобы не переносить файлы вручную)

Настраивается один раз. Потом правки кода сами заливаются в проект Apps Script
при каждом изменении — копировать файлы больше не нужно.

### Что сделать один раз (нужен компьютер с Node.js)
1. Установи инструмент: в терминале `npm install -g @google/clasp`
2. Войди в свой Google: `clasp login` (откроется браузер → разреши)
3. Открой созданный файл `~/.clasprc.json` (Windows: `C:\Users\<ты>\.clasprc.json`),
   скопируй **всё** содержимое.
4. GitHub: репозиторий → **Settings → Secrets and variables → Actions →
   New repository secret**. Имя `CLASPRC_JSON`, значение — вставь скопированное.

Готово — робот сам заливает код в проект (видно по ссылке `/dev`).

### Чтобы обновлялась и ЖИВАЯ ссылка (/exec) сама
5. Там же → вкладка **Variables → New variable**. Имя `APPSSCRIPT_DEPLOYMENT_ID`,
   значение — ID развёртывания (Развернуть → Управление развёртываниями →
   строка «Идентификатор развёртывания»).

Теперь `/exec` обновляется автоматически.
