# setup/ — настройка сервера Auron

## enable-https.sh — включить HTTPS на бэкенде (последний барьер к проду)

**Зачем.** Сейчас бэкенд Auron работает по `http://201.51.6.170:8000` (без шифрования).
Сайт на GitHub Pages — по HTTPS, а браузер **блокирует** обращения с защищённой страницы
на незащищённый адрес (mixed content). Поэтому в проде приложение не связывается с базой.
Плюс по HTTP пароли и деньги идут открытым текстом.

**Решение** — тот же приём, что уже работает в каталоге: домен `201-51-6-170.sslip.io`
(бесплатно, без регистрации) + Caddy (бесплатный автосертификат Let's Encrypt).

### Как включить (≈ 3 минуты)
1. Зайдите на сервер Auron (там, где Supabase на порту 8000), под root.
2. Запустите скрипт:
   ```
   bash enable-https.sh
   ```
3. Дождитесь строки `✅ Готово` и адреса `https://201-51-6-170.sslip.io`.
4. Откройте этот адрес в браузере — должен ответить (не «сайт не защищён»).
5. Сообщите ассистенту: «сервер на HTTPS, адрес https://201-51-6-170.sslip.io» —
   он поменяет адрес в `app/js/config.js`, бампнет кэш и задеплоит.

### Что скрипт НЕ трогает
Вашу базу и контейнеры Supabase не меняет — только добавляет HTTPS-фасад (Caddy).
Обновление `.env` Supabase (для ссылок в письмах) — по желанию, скрипт подскажет команды.

### После включения — что поменяется в приложении
Одна строка в `app/js/config.js`:
```
window.SUPABASE_URL = 'https://201-51-6-170.sslip.io';   // было http://201.51.6.170:8000
```
и бамп версии кэша в `app/sw.js`. Это сделает ассистент по вашему сигналу.
