# ТЗ на дизайн интерфейса — ERP-дашборд «Вай Маркет»

Документ можно целиком отдать Клоду (или дизайнеру) как задание.
Он самодостаточный: в нём есть контекст, правила оформления, все экраны и критерии приёмки.

---

## 1. Что за программа

Автономный веб-дашборд магазина 24/7 «Вай Маркет». Папка = программа: открывается двойным
кликом с флешки или с рабочего стола, работает **без интернета и без сервера**, все расчёты
идут в браузере, данные пишутся в файл внутри той же папки.

Внутрь загружаются выгрузки 1С (продажи, остатки, цены поставщиков, накладные, кассовые ордера,
списания, возвраты) и книга владельца в Excel. Плюс владелец каждый день дописывает данные руками
прямо в программе: смена и касса, приход товара, оплата поставщику, расход, списание, табель.

Технически: один HTML + `styles.css` + несколько JS-файлов. Никаких фреймворков, никакого сбора
шрифтов и иконок из интернета — всё лежит локально. Дизайн задаётся **только** через `styles.css`
(CSS-переменные + классы компонентов), разметку генерирует JS из готовых классов.

## 2. Кто им пользуется

Владелец магазина. Не программист. Смотрит:
- утром — с телефона, 1–2 минуты, стоя (сколько должны, кому платить сегодня, всё ли сошлось в кассе);
- вечером — с ноутбука, 10–20 минут (заносит день, смотрит отчёты, сравнивает цены поставщиков).

Иногда экран видят посторонние (продавец, поставщик), поэтому нужен режим «скрыть суммы».

**Главный вопрос, на который экран должен отвечать за 3 секунды:**
сколько я должен поставщикам, что горит прямо сейчас и кому платить в первую очередь.

## 3. Принципы оформления

1. **Стиль iOS.** Светлая тема по умолчанию, тёмная — автоматически по настройке системы.
   Скруглённые карточки, мягкая тень, много воздуха, тонкие разделители.
2. **Одна главная цифра на экран.** Крупная (42px), остальное мельче. Не пять равных плиток.
3. **Списки вместо таблиц** там, где строк мало и важна читаемость. Таблица — только для
   больших массивов (склад, цены, ABC).
4. **Цвет = смысл, не украшение.** Зелёный — хорошо, красный — плохо/долг, оранжевый —
   требует внимания, синий — действие и ссылки. Больше цветов не вводить.
5. **Никакого жаргона.** «Сколько должны поставщикам», а не «кредиторская задолженность».
   Подписи объясняют цифру: «за 30 дней», «из них просрочено».
6. **Ничего лишнего на экране.** Если блок не помогает принять решение — его нет.
7. **Кнопок-заглушек не бывает.** Кнопка либо работает, либо её нет.

## 4. Токены оформления

Всё оформление — через CSS-переменные в `:root`. Никаких «магических» цветов внутри правил.

```
Светлая тема
--bg #F2F2F7        фон страницы
--bg-elev #FFFFFF   карточки, списки
--bg-inset #F7F7FA  строка «Итого», подсказки в формах
--label #000        основной текст
--label-2 rgba(60,60,67,.62)   вторичный текст
--label-3 rgba(60,60,67,.35)   плейсхолдеры, шевроны
--separator rgba(60,60,67,.14) линии
--fill rgba(120,120,128,.12)   фон обычных кнопок и полей поиска

Тёмная тема (@media prefers-color-scheme: dark)
--bg #000  --bg-elev #1C1C1E  --bg-inset #2C2C2E
--label #FFF  --label-2 rgba(235,235,245,.62)  --separator rgba(84,84,88,.5)

Акценты (светлая → тёмная)
--blue   #007AFF → #0A84FF   действия, ссылки, активный пункт меню
--green  #34C759 → #30D158   прибыль, оплачено, сходится
--red    #FF3B30 → #FF453A   долг, просрочка, недостача
--orange #FF9500 → #FF9F0A   внимание, частично оплачено, скоро срок
--purple #AF52DE  --teal #30B0C7  --indigo #5856D6  --pink #FF2D55  — только для графиков

Скругления:  --r-card 16px  --r-inner 12px  --r-pill 980px
Тень карточки: 0 1px 2px rgba(0,0,0,.05), 0 6px 20px rgba(0,0,0,.04)
Тень модалки:  0 20px 60px rgba(0,0,0,.28)
```

**Шрифт** — системный, без загрузки из сети:
`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI Variable Text", "Segoe UI", Inter, Roboto, system-ui, sans-serif`.
Базовый размер 15px, межстрочный 1.45.

**Размеры текста:** заголовок страницы 32px/700 (на телефоне 27px), главная цифра 42px/700
(на телефоне 32px), заголовок карточки 17px/650, цифра в плитке 26px/680, строка списка 15.5px/550,
подпись 13px, надзаголовок раздела меню 11px/600 капсом.

**Все суммы и числа — моноширинными цифрами** (`font-variant-numeric: tabular-nums`),
чтобы столбцы не «прыгали». Деньги выравниваются вправо.

**Иконки — эмодзи.** Никаких шрифтов иконок и SVG-спрайтов: программа должна работать без интернета,
а эмодзи есть в любой системе.

## 5. Каркас окна

```
┌─────────────┬──────────────────────────────────────────────┐
│  Вай Маркет │ 🔍 поиск  [Сегодня|Неделя|Месяц|Квартал|Всё] │
│  Магазин 24/7│              ＋Записать  📂Обновить  👁      │
│             ├──────────────────────────────────────────────┤
│  ГЛАВНОЕ    │                                              │
│  🏠 Сегодня │        страница, максимум 1180px,            │
│  ДЕНЬГИ     │        центрирована, отступ 26px,            │
│  📊 Пульт   │        блоки через 22px                      │
│  🤝 Поставщ.│                                              │
│  …          │                                              │
│─────────────│                                              │
│ ● Сохранено │                                              │
└─────────────┴──────────────────────────────────────────────┘
```

- **Боковое меню** 258px, полупрозрачный фон с размытием (`backdrop-filter: blur(20px)`),
  пункты сгруппированы надзаголовками: Главное · Деньги · Товары · Отчёты · Ещё.
  Активный пункт — синяя «пилюля» с белым текстом. Справа в пункте может быть красный
  счётчик-бейдж (например, число просроченных оплат).
- **Внизу меню** — индикатор сохранения: зелёная точка «Сохранено в папку» / серая «Не настроено».
- **Верхняя панель**: поиск (растёт, но не шире 380px), сегментированный переключатель периода,
  синяя кнопка «＋ Записать», кнопка «📂 Обновить из 1С», кнопка-глаз «Скрыть суммы».
- **Режим приватности**: класс `priv` на `<body>`, все суммы получают `filter: blur(7px)` и
  не выделяются мышью. При печати размытие снимается.

## 6. Компоненты

| Компонент | Как выглядит | Где применяется |
|---|---|---|
| `hero` | белая карточка, подпись 14px сверху, цифра 42px, пояснение снизу | главная цифра экрана |
| `stat` | плитка в сетке `auto-fit, minmax(210px,1fr)`, подпись + цифра 26px + мелкая приписка | 3–6 показателей подряд |
| `card` | шапка (заголовок + примечание справа) и тело | обёртка для списка, таблицы, текста |
| `list` / `row` | строка 56px: квадратная иконка 30px, заголовок + подпись, значение справа, шеврон | всё, где строк до ~30 |
| `table.data` | 14px, липкая шапка, тонкие линии, столбцы `num` вправо, строка «Итого» на фоне `--bg-inset` | склад, цены, ABC |
| `badge` | пилюля 12px на подкрашенном фоне 12–16% прозрачности | статусы: Оплачено / Частично / Долг |
| `segmented` | серый контейнер, активная кнопка — белая с тенью | периоды, вкладки внутри экрана |
| `banner` | цветная подложка без тени, слева текст, справа кнопка | предупреждения и подсказки |
| `sheet` | модальное окно 560px, радиус 20px, липкая шапка с крестиком | формы ввода и подробности |
| `toast` | тёмная плашка снизу по центру, исчезает сама | «Сохранено», «Загружено 5 файлов» |
| `empty` | 40px отступ, текст по центру, выделенная жирным подсказка что сделать | пустой экран |
| `chart-box` | белая карточка высотой 260px под график | дашборд, отчёты |

**Кнопки:** высота 38px, радиус 10px. `btn` — серая, `btn-primary` — синяя, `btn-danger` —
красный текст на сером, `btn-plain` — синий текст без фона, `btn-sm` 30px, `btn-lg` 46px,
`btn-icon` — квадратная 38×38.

**Формы** — списком в стиле iOS: строка 50px, слева подпись (46% ширины), справа поле без
рамки с выравниванием вправо. Внизу подсказка на фоне `--bg-inset`, ещё ниже — кнопки
«Отмена» и «Сохранить» справа.

## 7. Экраны (22)

**Главное**
1. **Сегодня** — главная цифра «Должны поставщикам», под ней плитки (выручка, прибыль, наличные
   в кассе, расхождение), затем список «Требует внимания» (просрочки, оплатить сегодня, пора
   заказать, заканчиваются сроки), затем быстрые кнопки записи.

**Деньги**
2. **Пульт** — короткий финансовый срез дня и месяца: приход, расход, прибыль, остатки по
   наличным / карте / переводу.
3. **Поставщики** — сколько кому должны, список поставщиков с суммой и сроком, телефон
   ссылкой (`tel:`), рядом лучшая цена по товару.
4. **Касса и смены** — таблица смен: дата, смена (день 09:00–21:00 / ночь 21:00–09:00), кассир,
   наличные / карта / перевод, выдано, факт, расхождение (зелёное/красное).
5. **Расходы** — журнал расходов по статьям.
6. **Зарплата** — табель, начислено, авансы, остаток к выплате.
7. **База операций** — единый журнал: дата · смена · кассир · тип (Приход/Расход/Долг) ·
   категория · способ оплаты · сумма · расхождение · комментарий. С фильтрами и правкой строки.
8. **Выплаты** — план оплат поставщикам, календарь месяца: дни с оплатами подсвечены,
   просроченные — красным.

**Товары**
9. **Склад** — 10 000+ позиций, таблица с поиском, остаток, закуп, розница, группа.
10. **Заказы** — что пора заказать (точка заказа), сколько заказать.
11. **Сроки годности** — списком: ≤2 дней красным, 3–5 дней оранжевым, просрочено — «снять с полки».
12. **Списания** — потери по причинам, суммы в закупе и в рознице.

**Отчёты**
13. **Дашборд** — графики: выручка по дням, структура расходов, приход/расход по способам оплаты.
14. **Отчёт за месяц** — с колонкой сравнения с прошлым месяцем (стрелка ↑/↓ и процент).
15. **Отчёт за день** — как выглядит один день целиком.
16. **Прибыль (P&L)** — сверху вниз: выручка → себестоимость → валовая прибыль → расходы → чистая прибыль.
17. **Безубыточность** — порог месяца и дня, запас прочности, в какой день месяца выходим в плюс.
18. **ABC-анализ** — товары по вкладу в выручку, классы A/B/C.
19. **Цены поставщиков** — по одному товару цены разных поставщиков, лучшая — зелёным.

**Ещё**
20. **Поиск** — по товару, штрихкоду, поставщику, телефону.
21. **Данные и файлы** — что загружено, когда, куда сохраняется база, экспорт и резервная копия.
22. **Настройки** — ставки, аренда, налоги, пороги сроков и долга, свои справочники
    (категории, кассиры, смены, поставщики).

## 8. Состояния

- **Пусто (ничего не загружено):** блок `empty` с одной понятной фразой и кнопкой действия —
  «Данные ещё не загружены. Нажмите **📂 Обновить из 1С** и выберите папку с выгрузками».
- **Пусто за выбранный период:** не показывать нули. Показать оранжевый баннер
  «За «Сегодня» записей нет — показываю за всё время» и вывести данные за всё время.
- **Долгий разбор файлов:** тост «Читаю файлы…», кнопки не блокировать.
- **Ошибка файла:** тост с именем файла и понятной причиной, остальные файлы всё равно загрузить.
- **Сохранение в папку недоступно (Safari):** баннер «Данные хранятся внутри браузера.
  Сделайте копию кнопкой» — без пугающих слов.

## 9. Телефон (≤860px)

- Боковое меню скрывается, вместо него кнопка «☰» слева в верхней панели: открывает нижний
  лист со всеми экранами и действиями.
- Поиск и переключатель периода переносятся на вторую строку во всю ширину.
- Кнопка «＋ Записать» растягивается, «Обновить из 1С» скрывается (на телефоне файлов нет).
- Плитки — в 2 столбца, при ширине ≤440px — в 1.
- Формы: подпись переезжает над полем, поле по левому краю, **шрифт 16px** — иначе iOS
  приближает страницу при вводе.
- Модальные окна прилипают к низу экрана и скруглены только сверху (как лист в iOS).
- Все нажимаемые элементы — не меньше 44px по высоте.
- Таблицы прокручиваются горизонтально внутри своей карточки, страница вбок не едет.

## 10. Печать (PDF)

По `@media print`: убрать меню, верхнюю панель и все кнопки; фон белый; у карточек вместо
тени — светлая рамка; блоки не разрывать между страницами; размытие сумм снять.

## 11. Чего делать нельзя

- Подключать шрифты, иконки, CSS или JS из интернета — программа работает офлайн.
- Вводить новые акцентные цвета помимо перечисленных.
- Делать плотные таблицы там, где хватает списка.
- Показывать больше одной «главной цифры» на экране.
- Оставлять кнопки, которые ничего не делают.
- Терять данные при ошибке ввода: форма закрывается только после успешного сохранения.
- Писать термины из бухгалтерии без расшифровки.

## 12. Как принимаем работу

1. Открыть `Дашборд_ВайМаркет.html` двойным кликом, без интернета — всё оформление на месте.
2. Экран «Сегодня» отвечает на три главных вопроса без прокрутки на ноутбуке 1440×900.
3. Переключение системной темы на тёмную не ломает ни один экран, текст везде читаем.
4. Ширина 390px (iPhone): меню открывается, формы заполняются без приближения, страница
   не едет вбок ни на одном из 22 экранов.
5. Кнопка «глаз» скрывает все суммы и только суммы.
6. Печать любого отчёта даёт чистый PDF без меню и кнопок.
7. В `styles.css` нет ни одного цвета мимо переменных `:root`.
