## Найдено и воспроизведено

1. **Обмен с 1С, тупик связи.** Внешний товар связан с карточкой, которую сняли с продажи. Предпросмотр без ошибок, применение отказывает при любом выборе. Исправлено (63b96785), тест.
2. **Обмен с 1С, единица.** Смена шт→кг у связанного товара обнаруживалась только при применении и откатывала весь пакет. Теперь видна в предпросмотре (63b96785), тест.
3. **XLSX.** Название с U+FFFF давало повреждённый лист. Исправлено (3c65cc20), тест.
4. **Повтор команды.** Тот же запрос с другим порядком полей JSON отклоняется как «Ключ повтора уже использован». Низкий риск (браузер отправляет одинаково), не исправлялось.

## Нужны решения владельца (в коде не менялось)

1. **Нулевая цена из 1С.** Строка с ценой `0` проходит предпросмотр и после подтверждения ставит розничную цену 0 у существующей карточки (проверено). Предлагаю: блокировать 0 как ошибку строки.
2. **Самоподтверждение.** Управляющий (владелец/администратор/бухгалтер) может сам создать, отправить и подтвердить своё списание. Предлагаю: подтверждает другой человек; владелец — исключение.
3. **Интернет-тест через туннель.** Общий лимит входа 30 попыток в минуту на всех: любой, у кого есть ссылка, может заблокировать вход всем. Сеансы бессрочные (persistentSessions). Для локальной сети приемлемо, для интернета — нет. Предлагаю до интернет-теста: лимит по логину без общего блока и срок сеанса.
4. **CommerceML.** Файл предложений, где есть товар не из этого же пакета, отклоняется целиком. Для реальной выгрузки 1С это вероятно; нужен образец.
