## Найдено и воспроизведено

1. **Обмен с 1С, тупик связи.** Внешний товар связан с карточкой, которую сняли с продажи. Предпросмотр без ошибок, применение отказывает при любом выборе. Исправлено (63b96785), тест.
2. **Обмен с 1С, единица.** Смена шт→кг у связанного товара обнаруживалась только при применении и откатывала весь пакет. Теперь видна в предпросмотре (63b96785), тест.
3. **XLSX.** Название с U+FFFF давало повреждённый лист. Исправлено (3c65cc20), тест.
4. **Повтор команды.** Тот же запрос с другим порядком полей JSON отклоняется как «Ключ повтора уже использован». Низкий риск (браузер отправляет одинаково), не исправлялось.

## Решения владельца (2026-10-21)

1. **Нулевая цена из 1С** — вариант А: строка отклоняется, прежняя цена не меняется. Сделано (1f5f636f).
2. **Самоподтверждение списания** — второй человек не нужен. Код не менялся.
3. **Интернет-тест** — исправить до теста. Сделано (4be1f6d7). Локальный запуск по-прежнему держит вход до выхода.
4. **Образцы 1С** — получены 13 файлов. Это не CommerceML, а отчёты 1С в XLS/XLSX. Разбор: docs/1C-SAMPLES-ANALYSIS.md. Файлы в репозиторий не добавлены.

Права ролей и чужие документы (сервер берёт автора и роль из сеанса); CSRF + Origin + Host + Sec-Fetch-Site; деньги — десятичная строка в копейки без float, кол-во — тысячные через BigInt; откат всего пакета (SAVEPOINT внутри BEGIN IMMEDIATE); дубли по повтору команды, повтору пакета и двум предпросмотрам; DOCTYPE/сущности в XML запрещены, глубина и число узлов ограничены; размер тела запроса ограничен; формулы в XLSX не исполняются (inlineStr).
