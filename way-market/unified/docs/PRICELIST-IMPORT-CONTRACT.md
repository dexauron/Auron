# Импорт «Прайс-лист 1С» (XLS/XLSX) — предлагаемый контракт

Статус: **предложение, не реализовано**. Ждёт решения Адама. Составлено 2026-10-21 по разбору образцов (docs/1C-SAMPLES-ANALYSIS.md) и ревью ChatGPT (10 пунктов). Сервер и тесты делает Claude, экран — ChatGPT, после того как API зафиксирован здесь. Боевую 1С не трогаем.

Существующий небольшой импорт CSV/JSON/CommerceML (до 50 строк) остаётся без изменений. Новый процесс отдельный.

## Правила

1. **Источники.** Прайс-лист обязателен. Файл единиц или остатков необязателен и соединяется **по коду 1С**, а не по названию. Если единица не определена однозначно, это ошибка строки, без подстановки «шт».
2. **Чтение.** XLS (BIFF) и XLSX читает сервер, тип файла определяется по содержимому. Формулы и макросы не исполняются. Сервер находит лист и строку заголовков и предлагает их на выбор; пользователь может указать лист, строку заголовков и столбцы вручную.
3. **Идентичность.** Внешний ID — это код 1С, строка с ведущими нулями в рамках sourceId. Код 1С, кассовый код, артикул и штрихкод хранятся отдельно. Одинаковое название не повод сливать товары.
4. **Предпросмотр.** Возвращает jobId, версию задания, сведения об источниках (имя, лист, SHA-256) и счётчики без двойного счёта: строк найдено = групп + итогов + товаров; товаров = готово + ошибок; готово = создать + обновить + без изменений; дубли считаются внутри ошибок. Ещё возвращаются несколько примеров готовых строк и постраничные ошибки с файлом, листом и номером строки Excel.
5. **Ошибки.** Пустая или нулевая цена, неизвестная единица, конфликт кода или штрихкода и неоднозначное сопоставление — это ошибки. Корректные строки применяются только после явного подтверждения «ошибочные N строк исключаются». Молча строки не пропускаются.
6. **Применение.** Размер пакета объявляет сервер (предложение — до 2 000 строк). У применения есть ключ повтора, версия предпросмотра и сохранённый прогресс. Повтор после потери ответа или перезапуска не создаёт дублей.
7. **Частичное выполнение.** Каждый пакет атомарен, но задание целиком — нет. Статусы: `ready`, `applying`, `paused`, `partial`, `done`, `cancelled`. Отмена останавливает следующие пакеты и не обещает отката уже записанных.
8. **Объём.** Обязательна проверка на 19 355 синтетических товарах: время, память, отзывчивость сервера, повторный запуск, резервная копия в пределах лимита архива 32 МиБ. Обход каталога и событий на каждую строку, как в текущем обработчике, недопустим: нужны индексы и словари.
9. **Ограничения.** Сервер ограничивает размер файла, распакованный размер XLSX, число листов и ячеек, объём сохраняемых ошибок. Значения ограничений отдаются в API. Интерфейс не рисует все строки разом.
10. **Права.** Только владелец. CSRF, отзыв сеанса и его истечение работают как везде. Истёкший вход не отменяет подтверждённую серверную работу: после повторного входа виден её актуальный статус.

Деньги — десятичная строка, переводится в копейки без float. Цена должна быть больше 0. Каждый пакет перед записью заново проверяет цену, единицу и версию карточки, не доверяя сохранённому предпросмотру (урок исправления 2026-10-21).

## API (черновик)

| Метод | Путь | Тело / ответ |
|---|---|---|
| POST | `/api/unified/1c/pricelist/upload` | `{requestId, profileId, role: 'prices'|'units', name, bytesBase64}` → `{fileId, sha256, sheets:[{name, rows, headerCandidates}]}` |
| POST | `/api/unified/1c/pricelist/preview` | `{requestId, profileId, expectedVersion, prices:{fileId, sheet, headerRow, columns}, units?:{…}}` → `{jobId, version, counts, samples, limits}` |
| GET | `/api/unified/1c/pricelist/jobs/:id/errors?page=` | постраничные ошибки |
| POST | `/api/unified/1c/pricelist/apply` | `{requestId, jobId, expectedVersion, excludeErrors: true}` → состояние задания |
| GET | `/api/unified/1c/pricelist/jobs/:id` | `{status, written, excluded, remaining, batches, lastError}` |
| POST | `/api/unified/1c/pricelist/cancel` | `{requestId, jobId, expectedVersion}` |

Тело загрузки идёт отдельным лимитом. Сам размер обсуждается: прайс-лист в образце весит около 7 МБ в XLS.

## Не входит

Остатки, документы, проведение, упаковки (пересчёт коэффициентов), закупочные цены поставщиков. Причины списаний и возвратов из 1С хранятся отдельным полем, а не заменяют статьи; сопоставление со справочниками 1С задаётся отдельно.
