# Возвраты и списания — Way Market 0.18

## Как оформить документ

1. Войти под своим аккаунтом. Открыть «Возвраты и списания» в основном меню; на телефоне — через «Ещё».
2. Нажать «Новое списание» или «Возврат поставщику». Для возврата указать поставщика. Проверить дату и склад.
3. Выбрать статью и причину для новых строк, например «Овощи и фрукты» и «Испорчен». Найти товары по названию, коду кассы, артикулу или штрихкоду, добавить их. В каждой строке можно изменить статью, причину и комментарий.
4. Указать количество в базовой единице карточки. Для штук — целое; для кг, л и м — до трёх знаков после запятой. Упаковки самостоятельно не пересчитываются. Один товар — одна строка документа.
5. Нажать «Сохранить черновик», затем «Отправить на проверку». Сохранённый документ доступен после повторного входа. Ввод до сохранения остаётся несохранённым; при ошибке связи не считать документ отправленным.
6. Владелец, администратор или бухгалтер проверяет документ и подтверждает его либо возвращает на доработку с причиной. При доработке сотрудник редактирует документ и повторно отправляет его.
7. В подтверждённом документе нажать «Скачать Excel». Новые изменения в подтверждённый документ не вносятся. Черновики, документы на доработке и на проверке можно отменить с причиной. История сохраняется.

## Статьи и причины

Это разные поля. Статья определяет выбранную категорию учёта, причина объясняет конкретное действие. Начальные статьи: «Овощи и фрукты», «Молочная продукция», «Бакалея», «Прочие товары». Через «Настроить статьи» управляющий может переименовать, добавить или отключить статью. Это пользовательские категории Way Market: их соответствие статьям расходов 1С настраивается отдельно.

Причины вводятся свободно, есть подсказки: «Испорчен», «Просрочка», «Повреждена упаковка», «Неправильный заказ», «Брак», «Другое». Для каждой строки причина обязательна. Изменение справочника статей не переписывает историю уже сохранённых документов.

## Доступ

| Роль | Создание | Просмотр | Подтверждение | Excel |
|---|---|---|---|---|
| Сотрудник, кассир | Свои документы | Свои | Нет | Свои подтверждённые |
| Владелец, администратор, бухгалтер | Да | Все документы сотрудников | Да | Подтверждённые |
| Внешний торговый представитель | Нет | Нет | Нет | Нет |

Защита действует на сервере, а не только на кнопках. Автор и сведения о товаре берутся из базы; подмена автора или названия из браузера не принимается. Управляющий может исправить доступный черновик; история хранит автора изменения. Подтверждение самим управляющим собственного документа разрешено, обязательное правило двух разных лиц не введено.

## Excel и загрузка в 1С

Формат — настоящий XLSX, два листа. «Товары» начинается с заголовков в первой строке, без объединённых ячеек и промежуточных итогов. «Документ» содержит номер, вид, дату, склад, поставщика, автора, подтверждение, источник, версию и комментарий.

| Столбец товаров | Содержимое |
|---|---|
| № | Порядок строки |
| Наименование | Название товара на момент сохранения |
| Количество | Число в базовой единице |
| Единица | шт / кг / л / м |
| Код кассы | Текст, ведущие нули сохраняются |
| Артикул | Артикул из карточки |
| Штрихкод | Первый штрихкод базовой единицы; штрихкод упаковки не подставляется |
| Код 1С | Внешний идентификатор из выбранного источника, если соответствие уже подтверждено |
| Статья | Снимок названия статьи |
| Причина | Причина для строки |
| Комментарий | Пояснение строки |
| ID Way Market | Внутренний устойчивый идентификатор товара |

Цена и себестоимость не вычисляются и не подменяются розничной ценой: пользователь запросил количественный документ. Если обработке 1С нужны цена, налог, партия или организация, потребуется отдельный согласованный формат выгрузки.

Кассовый код, артикул и внешний идентификатор — разные сущности. Не считайте кассовый код автоматически кодом номенклатуры 1С. Для вашей обработки загрузки нужно один раз выбрать соответствующие столбцы и проверить их на тестовом документе. Готовая совместимость с произвольной конфигурацией 1С не заявляется. Без хотя бы одного кода, артикула, базового штрихкода или подтверждённого внешнего ID документ нельзя отправить на проверку.

Повторное скачивание не создаёт документ Way Market заново, но загрузка одного Excel дважды в 1С может создать два документа. Проверяйте номер перед загрузкой. Сам файл не способен запретить дубль внутри чужой обработки.

## Подготовка интеграции

Для подтверждённого документа доступен серверный контракт `way-market-goods/v1`: стабильный ID, версия, `idempotencyKey`, тип документа, источник и снимки строк. Получение контракта требует тех же прав, что выгрузка Excel. Автоматическая отправка явно отключена (`automaticSend: false`).

Будущий адаптер должен отдельно сопоставить склад, поставщика, статьи, единицы и номенклатуру с реальными ссылками конкретной 1С; согласовать вид документа, стоимость, налоги и правила проведения. Нужны сохраняемая очередь доставки, подтверждение результата со стороны 1С, защита от повторов и сверка. Наличие контракта не заменяет эти механизмы. Возврат в этой версии означает возврат поставщику; покупательские возвраты и возвраты чеков — другой процесс.

## Границы и сохранность

До 50 товаров в документе, до 100 статей. В списке показаны последние 200 доступных документов; поиск и фильтры относятся к этому списку. Объём подробного документа ограничен 60 000 байт события. История документов, статей и ключей повтора сохраняется штатной резервной копией в account_events. Новые таблицы и миграция схемы не требуются.

Документ не изменяет складские остатки, финансы, задолженность поставщику или кассовый лист. Это оформление и согласование для дальнейшего учёта. Работа с конкретной 1С и запуск на Windows пользователя в этой работе не проверялись. Архив содержит код, не обновляет работающий сервер сам по себе.

Перед установкой создайте штатную резервную копию, распакуйте новую версию отдельно и сохраните существующий каталог данных. Начните проверку на тестовой копии. Не заменяйте пользовательскую базу файлами архива.
