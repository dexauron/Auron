# Тесты каталога

Проверки лежат здесь, а не во временной папке: временная папка при
перезапуске контейнера обнуляется, и набор тестов уже трижды пропадал.

## Как запустить

```bash
# из корня репозитория, один раз за сессию — поднять статический сервер
python3 -m http.server 8123 --directory catalog &

# все проверки
NODE_PATH=/opt/node22/lib/node_modules node catalog/tests/run.js

# одну
NODE_PATH=/opt/node22/lib/node_modules node catalog/tests/navigation.js
```

Каждый файл печатает строки `OK:` / `FAIL:` и в конце итог.
Код возврата 1 — есть провалы.

## Правило

Тест, который никогда не падал, ничего не доказывает. Каждую новую проверку
прогоняй на СТАРОМ коде (`git stash`) и убеждайся, что она валится, — иначе
она проверяет не то, что кажется.
