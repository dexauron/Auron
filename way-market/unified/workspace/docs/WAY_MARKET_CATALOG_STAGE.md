# Way Market — каталог TEST 0.7

19.10.2026. Отдельный этап разработки поверх финансов TEST 0.6. Все семь направлений остаются открытыми; см. WAY_MARKET_SEVEN_TASKS_STATUS.md. Исходные приложения не меняются, реальные данные не импортируются автоматически.

## Карточки

Владелец/администратор ведёт группы с вложенностью до восьми уровней, название, розничную цену, код кассы, артикул, бренд, базовую единицу (шт/кг/л/м), весовой признак, наличие, описание, массу/объём, жирность. Упаковка содержит явно заданное количество базовых единиц с точностью до 0,001; несколько штрихкодов могут обозначать разные упаковки. Масса/объём одной товарной единицы не подменяет количество единиц в коробке. Весовой товар требует единицу кг. Нельзя задать явный размер/жирность, противоречащие указанным в названии.

Штрихкод хранится строкой, ведущие нули сохраняются. Дубли новых штрихкодов и действующих кодов кассы блокируются. Старые неоднозначные штрихкоды без расширенного профиля допускаются для постепенного перехода с предупреждением; поиск не выдаёт такое совпадение за однозначное. Изменение существующей карточки требует причины и текущей версии; запись основной карточки, профиля, аудита и результата повторной команды атомарна. Старый API `/api/products` сохраняет прежние шесть полей и расширенные данные при редактировании.

## Поиск и соответствия

Поиск выполняется локально, без облачной модели и платного API. Поддерживаются отдельные словоформы, одна опечатка, ошибочная раскладка и транслитерация; примеры: «молко», «vjkjrj», «moloko». Запрос «молоко 0,9 л в наличии до 100 рублей» сочетает название, размер, явно отмеченное наличие и предел цены. Это набор ограниченных правил, а не понимание произвольного языка.

Владелец/бухгалтер выбирает поставщика и вставляет название из документа. Исходная строка хранится без изменения пробелов, кавычек и пунктуации; для поиска создаётся отдельный нормализованный ключ. Предлагаются похожие товары с основаниями и предупреждениями. Баллы сходства не являются вероятностью правильности. Различия массы/объёма/жирности уменьшают рейтинг даже при совпавшем штрихкоде или прежнем соответствии; неизвестные признаки и неоднозначные коды также показываются явно.

Автоматического принятия и пересчёта нет. Человек проверяет товар и единицу/упаковку, затем явно подтверждает соответствие; сервер проверяет актуальные версии товара и поставщика. Память раздельна для поставщиков, может быть отключена с причиной. Активная связь не позволяет незаметно удалить связанную упаковку. История и исходное название сохраняются. Сопоставление пока вызывается вручную и не является готовым импортом накладной.

## Розничная витрина

`/shop` доступна без аккаунта, но только через уже разрешённый адрес/сетевой режим сервера. Это не публикация в интернете и не обход ограничений HTTPS/IP. Новые и восстановленные старые товары скрыты по умолчанию. Владелец/администратор отдельно включает розничную карточку. Архивный/скрытый товар исчезает из следующего ответа витрины.

Сервер выдаёт только разрешённые розничные поля: название, цена, группа, бренд, единица, наличие, описание, масса/объём и жирность. Коды кассы, артикулы, штрихкоды, соответствия поставщиков, авторы/причины, касса и финансы не входят в ответ. Браузер не загружает эти данные для последующего скрытия.

Покупатель составляет список в памяти открытой страницы, меняет количество и копирует текст с предварительным итогом. Штучные количества целые, для кг/л/м допускаются три дробных знака. Цена и наличие требуют подтверждения магазином; список не создаёт заказ, резерв, долг или оплату. После перезагрузки список исчезает. WhatsApp/номер магазина и отправка сообщений не подключены.

## Копии и границы

Архив v5 включает группы, профили, соответствия, их версии, аудит и ключи повторов. При восстановлении проверяются связи и история, создаётся отдельная база без сеансов. Читаются v1–v4 с пустыми отсутствующими таблицами. Сетевой запуск требует новой проверенной копии с каталогом.

Ещё нужны фото/вложения, сканирование камерой, проверяемая миграция исходного каталога и файловый импорт, заказы покупателей, WhatsApp, испытание большого каталога/Windows/Safari и реальных устройств магазина. Нет offline PWA, автосохранения форм и облачного ИИ. Тестовые данные вымышленные; готовность к промышленной эксплуатации не заявляется.
