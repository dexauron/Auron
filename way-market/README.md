# Way Market — текущая граница реализации

Работа ведётся только в `way-market/unified-system`. Эта папка пока содержит чистые расчёты, проверки готовности данных, нормализатор **прочитанных ячеек** одного отчёта 1С и демонстрационные макеты. Это не готовая учётная система и не подключённый ИИ.

| Часть | Что действительно есть | Чего пока нет |
| --- | --- | --- |
| `finance/` | Маржа, наценка, целевая цена, прибыль периода в целых копейках, проверка наличия подтверждений | Финансового журнала, связанного с базой и ролями |
| `importers/` | Разбор массива ячеек отчёта «Продажи», сверка строк/итога, блокировка неподтверждённой базы НДС, предпросмотр повтора | Чтения бинарного XLS/XLSX в приложении, транзакционного применения и постоянной истории импорта |
| `mockups/` | Кликабельные сценарии шести ролей на вымышленных значениях; кассовая арифметика | Настоящей авторизации, сохранения, ИИ, памяти, прогнозов и реальных документов |

`app/`, `server/`, `webapp/`, `infra/`, `supabase/` — унаследованные варианты исходного приложения; они не являются проверенным новым бэкендом. `source-copies/catalog/` — эталонная копия. Не запускать унаследованные подключения с рабочими базами как тест нового продукта. Текущие дефекты и доказательства описаны в `docs/WAY_MARKET_AUDIT_2026-10-15.md`.

Публичный каталог и внутренняя программа в рабочем продукте должны иметь отдельные сборки. Переключатель роли в макете только для показа: он не защищает данные. Генеративная модель не должна определять проводки и формулы.

Проверка без установки зависимостей (Node.js 24):

```bash
node --test way-market/finance/*.test.mjs way-market/importers/*.test.mjs way-market/mockups/*.test.cjs
```

Успешный запуск этих тестов не заменяет реальную авторизацию, сверку с данными магазина, испытание Windows-установщика и восстановление базы. Новый workflow выполняет только эти проверки, без развёртывания и подключения к сервисам.
