# Way Market — текущая граница реализации

Работа ведётся только в `way-market/unified-system`. Добавлена первая **локальная тестовая сверка** в `local-app/`: адаптивный экран, сохранение в отдельной SQLite, история исправлений и печать. Это не готовая учётная система и не подключённый ИИ. Запуск и ограничения — `local-app/README.md`.

| Часть | Что действительно есть | Чего пока нет |
| --- | --- | --- |
| `local-app/` | Локальный HTTP-сервис Node.js 24, SQLite, ввод наличной сверки, версии исправлений, защита повторов, печать; проверяемый архив и восстановление в новый файл | Авторизации/ролей, журнала денежных счетов, настраиваемых формул, импорта 1С, автоматических внешних копий и сетевого доступа |
| `finance/` | Маржа, наценка, целевая цена, прибыль периода в целых копейках, проверка наличия подтверждений | Финансового журнала, связанного с базой и ролями |
| `importers/` | Разбор массива ячеек отчёта «Продажи», сверка строк/итога, блокировка неподтверждённой базы НДС, предпросмотр повтора | Чтения бинарного XLS/XLSX в приложении, транзакционного применения и постоянной истории импорта |
| `mockups/` | Кликабельные сценарии шести ролей на вымышленных значениях; кассовая арифметика | Настоящей авторизации, сохранения, ИИ, памяти, прогнозов и реальных документов |

`app/`, `server/`, `webapp/`, `infra/`, `supabase/` — унаследованные варианты исходного приложения; они не являются проверенным новым бэкендом. `source-copies/catalog/` — эталонная копия. Не запускать унаследованные подключения с рабочими базами как тест нового продукта. Текущие дефекты и доказательства описаны в `docs/WAY_MARKET_AUDIT_2026-10-15.md`.

Публичный каталог и внутренняя программа в рабочем продукте должны иметь отдельные сборки. Переключатель роли в макете только для показа: он не защищает данные. Генеративная модель не должна определять проводки и формулы.

17.10.2026 владелец подтвердил размещение на выделенном Windows-компьютере AURON-SERVER. Добавлен явный `start-server-test.cmd` с единой тестовой папкой `%ProgramData%\WayMarket-Test`. Пока доступ только через браузер самого сервера/RDP; роли, HTTPS и LAN-доступ ещё не реализованы. Решение и ограничения: `docs/WAY_MARKET_SERVER_DECISION.md`.

В 0.4 добавлены второй источник наличных, общие выплаты поставщикам и зарплаты, предыдущие передачи и общая безналичная сверка с выбором основы (готовый итог либо продажи/возвраты). История, печать и архив сохраняются; старые снимки совместимы. Комиссии, банковское зачисление и согласования ещё не реализованы. Решения владельца и проект контроля: `docs/WAY_MARKET_CONTROL_AND_APPROVALS.md`; расчёт безналичных: `docs/WAY_MARKET_NONCASH_STAGE.md`.

В 0.5 та же математика доступна в пошаговом интерфейсе для обычных сотрудников: пять задач, раскрываемые подробности, явное «Не было», ошибки у поля, полная форма по запросу. Дизайн адаптируется к телефону, планшету и компьютеру. Сетевая доступность/реальная авторизация ещё не включены. Подробности: `docs/WAY_MARKET_SIMPLE_UX.md`.

Проверка без установки зависимостей (Node.js 24):

```bash
node --test way-market/finance/*.test.mjs way-market/importers/*.test.mjs way-market/mockups/*.test.cjs way-market/local-app/*.test.mjs
```

Успешный запуск этих тестов не заменяет реальную авторизацию, сверку с данными магазина, испытание Windows-установщика и восстановление базы. Новый workflow выполняет только эти проверки, без развёртывания и подключения к сервисам.
