# Way Market — локальная тестовая сверка 0.1

Первый сохраняемый сценарий новой системы. Только синтетические данные и один локальный пользователь. Это не готовая финансовая программа, не смена 1С и не проведение платежей.

## Запуск Windows

1. Установить поддерживаемую исправленную версию **Node.js 24 x64** с официального https://nodejs.org/. Перезапустить терминал после установки. Зависимости npm устанавливать не нужно.
2. Распаковать эту папку целиком в отдельную папку, например `C:\WayMarket-Test\local-app`.
3. Запустить `start-windows.cmd` обычным пользователем. Права администратора для приложения не нужны.
4. Дождаться сообщения `Way Market TEST`, открыть **http://127.0.0.1:3210** в браузере **на сервере** (можно через уже подключённый RDP).
5. Нажать «Заполнить пример», проверить 25 000 ₽ к передаче и −200 ₽ расхождения, сохранить. Обновить страницу, открыть историю — запись должна остаться. Исправить пересчёт на 25 000 ₽, указать причину, сохранить версию 2, распечатать.
6. Остановка — Ctrl+C в окне запуска. Для повторного запуска открыть тот же CMD. Если порт занят, второй экземпляр сообщит об ошибке; не завершать незнакомые процессы автоматически.

На Windows Server 2025 с i3-2120/8 ГБ реальный запуск ещё не проверен. Выполнены Linux/Node 24 и Chromium проверки. Вся папка нужна целиком; HTML отдельно не работает. Интернет при запуске не нужен. ИИ и внешние сервисы отсутствуют.

## Данные

На Windows база создаётся в `%LOCALAPPDATA%\WayMarket-Test\cash-test.sqlite` текущего пользователя. На другой ОС — `~/WayMarket-Test`. Это отдельная тестовая база, не старый Auron Finance. Файл не публикуется HTTP-сервисом. При смене Windows-пользователя путь и база меняются.

SQLite: WAL, synchronous FULL, BEGIN IMMEDIATE, уникальная смена (дата + касса + номер), версии и идентификаторы запросов. Исправление добавляет снимок и причину, старую версию не переписывает. Версия формулы сохранена. Это история внутри приложения, **не защита от администратора**, который может изменить файл базы. Экспорт, восстановление и внешняя копия пока не реализованы. Не копировать только основной файл работающей WAL-базы как резервную копию.

## Правила

- Суммы вводятся текстом в рублях, преобразуются в целые копейки без floating-point разбора. Пробелы-разделители тысяч, экспоненты, отрицательный ввод и более двух десятичных знаков отвергаются. Максимум одного ввода — 999 999 999,99 ₽; арифметика BigInt с проверкой итогового диапазона.
- Наличные по Z должны уже учитывать возвраты, но ещё не вычитать перечисленные выплаты. Эта основа явно подтверждается. Другие форматы Z пока нужно сверить до использования; универсальной настройки формулы ещё нет.
- Ожидаемая передача = начало + наличные Z + прочие поступления − выполненные выплаты наличными − оставлено. Выплата картой/СБП и невыполненная выплата не уменьшают наличные.
- Заявление кассира и пересчёт бухгалтера — отдельные необязательные значения; пусто ≠ 0. Если пересчёт заполнен, имя бухгалтера обязательно. Имена являются введённым текстом, не подтверждённой идентичностью.
- Факт минус расчёт и принято минус заявлено — разные расхождения. Отрицательный расчёт отображается с предупреждением. Расхождение не считается доказанным хищением.
- Дата/касса/номер сохранённой смены неизменяемы в этом этапе. Для исправления ошибочной идентичности потребуется будущий сценарий отмены; не создавать второй документ вместо первого без разбора.
- Повторный запрос с тем же ID и содержимым возвращает ту же версию. Тот же ID с другим содержимым отвергается. Конкурентная устаревшая версия не перезаписывает новую. Одинаковая смена с другим request ID не создаётся.
- Печать берёт сохранённый снимок, не текущие несохранённые значения; бумажные подписи отдельно. Печатный тестовый бланк не заменяет обязательные формы бухгалтерского учёта.

## Сеть и доступ

Сервис слушает только **127.0.0.1:3210**. Нет параметра включения LAN. Не публиковать через туннель или reverse proxy и не открывать порт в роутере. Проверяются Host, Origin/Fetch-Site, CSRF-токен и размер запроса. Токен — защита от запросов посторонней веб-страницы, **не авторизация пользователей**. Другие программы и пользователи этого компьютера с локальным доступом не изолированы. Нет CORS, удалённых шрифтов, CDN, подключений к старым базам и ключей OpenRouter.
